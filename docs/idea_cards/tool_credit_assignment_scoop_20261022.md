## Notes

- **Main threat: BRPO (2505.13438).** It already publishes "the policy's own forced-answer scores at earlier truncation points, lambda-weighted, used as the reward baseline" for the thinking policy. A reviewer will read our method as "BRPO's V1 moved to multi-turn tool use." The parts of our method that remain distinct:
  - (i) The decision states are tool-turn boundaries with a crop/answer action. BRPO uses token-budget cuts.
  - (ii) The return is outcome-only, so the expected gradient equals RLOO exactly. BRPO's return is the dense anytime sum, so its objective already differs from outcome-only.
  - (iii) The baseline is an m-fork commit mean at the *current* state s_k times (1-lambda(k-1)). BRPO's V1 averages *earlier* budgets and is interpolated with the group mean.
  - (iv) The crop-only biased variant, an explicit probe of the stop-shaping term -pi(1-pi)(V_stop - J). Nothing I read has this; it is our clearest novelty.
  
  Our paper must cite BRPO and say directly that we use a forced-answer baseline in BRPO's style.
- **MRT (2503.07572)** uses the same forced-termination quantity under the same LLM, but as a reward bonus. **PAV** Sec 3.2 states that a mu=pi signal adds nothing as a reward, which motivates using it only as a baseline/credit device. Cite both for the "reward vs baseline" contrast.
- **Multi-turn tool side:** Critical-State RL (2609.24985, one month old, Salesforce) and RTMC (2604.11037) use action-independent per-state baselines from forks or matched states in tool-use RL, but with continuation values, not forced-commit values. IGPO and TRACE use per-turn "answer-now" likelihood signals in tool-use agents, but as rewards (teacher-forced; TRACE also uses a frozen reference model).
- **Not found:** a 2025-2026 paper that combines a forced-commit value with a baseline role in multi-turn tool use. The search was limited to WebSearch queries for SCST greedy baseline, stop-value baseline, answer-now baseline, early-exit value baseline, per-step MC commit baseline, intermediate answer probing, VLM crop credit, and forced-answer agentic RL. Coverage is not exhaustive: there was no local-corpus or Semantic Scholar citation chase of BRPO or MRT. **Next step: check the papers that cite BRPO** for a multi-turn or tool extension, since that is where a same_mechanism hit would most likely be.

### Takeaways for positioning

- **SHAPE (2604.06636) is the new must-cite.** It defines the identical quantity, Phi(s_k) as the mean of m forced-termination rollouts at boundary s_k, with the same notation. It uses that quantity as a potential-difference shaping term whose length-discounted gamma intentionally changes the optimum. Our contrast: the commit mean is used only as an action-independent baseline at tool-decision states, so the expected gradient equals outcome-only RLOO exactly. Our crop-only variant is then the *deliberate* biased probe, whereas in SHAPE the bias is the method itself.
- **MR-Search (2603.11327) is the multi-turn RLOO precedent.** It already argues "turn-level LOO baseline independent of current action, so unbiased" for agentic search. That baseline is a cross-trajectory mean, not a same-state fork commit value, so we should cite it for the unbiasedness framing.
- **CaRT (2510.08517) is the closest stop-decision work in a multi-turn setting.** It uses per-prefix forced-answer success, but from an external model, as labels/reward.
- The cluster of BRPO/MRT/SHAPE/RLCM/premature-confidence papers shows that "forced-answer MC value at intermediate states" is now a common quantity in 2025-2026. The novelty claim has to rest on (b) baseline-only with an exactly unchanged expected gradient, (c) tool-decision states in multi-turn VLM tool use, and the biased crop-only probe. It cannot rest on the quantity itself.
