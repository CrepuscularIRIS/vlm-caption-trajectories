## 3. Caption 设计：没有改成另一个任务

核心仍是 **短证据 Caption＋真实动作**：记录“看到了什么、属于哪个实例、还有什么没有确定”，再据此观察或提交答案。没有为了凑多步添加无用操作，也没有另建每个 domain 一套复杂协议。

| 组成 | 要表达的内容 | 本版核对方式 |
|---|---|---|
| 观测 | 只写当前已收到视图能够支持的视觉事实，保持简短 | 关键颜色、文字、数量、位置和读数逐图对照 |
| 实例绑定 | 说明事实属于哪个对象、图表、行列、年份、单位或候选 | 相同数值不代表同一对象；跨 crop 保持对应 |
| 证据缺口 | 尚未找到、被遮挡、无法区分、缺上下文时如实说清 | 不把“可能/看不清”直接变成确定事实 |
| 真实动作 | 根据缺口选择定位、放大、换区或终答 | 只引用此前已有视图；坐标留在动作字段 |
| 规则/计算 | 外部规则与基于图上读数的计算分开表述 | 不把领域知识、推断或计算伪装成视觉观测 |
| 更新/恢复 | 新证据推翻旧判断时明确更新；搜索未命中可换区 | 不强求出现 HOLD/REVISE 字面标签 |

典型完整路径是：`原图 → Caption＋crop → 实际返回视图 → Caption＋answer`。原图已经充分时，`原图 → Caption＋answer` 同样合格。Caption 中不口述 bbox 坐标；坐标动作由工具解释与执行。

历史 SFT 导出采用过可见 Caption 的标签映射。网页统一以 `<caption>` 展示这些原有短证据文字，**只规范显示标签，不改写内容、不补理由、不删步骤**；它们不是隐藏推理。模型内部不可见 reasoning token 不作为 SFT 目标文本，也不作为步数。

合理搜索未命中并不是关键事实错误：如实确认没有找到、换到有区分力的区域，具有教学价值。反复放大同一处却没有新证据不进入本版 KEEP。包含明确错误前缀的完整路径不能因最终答对而被洗白；恢复后缀须另行定义，本版不从不同模型拼接 recovery。

## 4. 从库存到当前版本：如何挑选

最初由 Luna、GLM、Sol 5.6、Grok 独立完成路径。答案判分、正常终止、格式及坐标检查先排除明显不合格结果；多模型答案一致性和材料覆盖用于安排审核顺序，**不能替代过程审核，也不等同于题目难度**。

早期共识批次优先至少两族能给出程序合格答案的题；后来对非 MME 库存、多步路径及既有问题做定向审查与换选。Astra、Gemini、K3 是在证据/绑定问题、低效搜索或残余题上补充完整新路径，不是把每一道题再全部重跑三个模型。新路径照样审核，不能因为模型更强就自动替换旧路径。

```text
四主模型生成库存 82,816
   ↓ CPU/终答资格 + 定向过程审核/换选/补充
V1 历史 KEEP 基线 5,277
   + CC 后续 4,750 条多 crop 审核中，531 KEEP 里的 113 条“全部 crop 有用”
   ↓ 同题重合 12；实际新增任务 101
V2 待核任务 5,378
   ↓ 严格逐图过程复核 + 原样导出资格
V2 主集 3,953
   + V2.1 新 K3 KEEP 26
   + V2.2 新 K3 KEEP 61
   ↓ 每题一条、任务与新增原图组去重
最终 V2.2：T 4,040 / Q 4,040 / G 3,690
```

上述箭头是构建沿革，不是同一随机总体的连续通过率实验。5,503 条过程审核含同题新旧不同路径；4,750 条 CC 后续审核只把符合筛选条件的部分送入 V2，因此不能将几份表的总数直接相加当独立任务数。

只保留完整 KEEP；当两条路径均合格时，看证据是否充分、动作是否有用，再选一条。有效多步值得保留，清楚原图上的有据直答也保留。没有固定教师配额、强制多步比例或“强模型一律优先”。

## 5. 经过了哪些审核

| 环节 | 输入/角色 | 检查内容 | 能说明什么 |
|---|---|---|---|
| 程序初筛 | 生成结果＋GT | 正常终止、答案判分、动作/坐标解析、无坐标话等 | 具备过程审核资格，不是视觉正确证明 |
| 历史 Sonnet/Opus 等审核 | 定向选出的完整路径 | 原有过程、关键事实、绑定、裁图效用判由 | 保留历史标签和依据，不能一概说是相同配置的全量多族盲审 |
| 本版 Codex 逐图复核 | 原图＋全部实际返回 crop＋完整路径 | 前缀可见证据、关键事实、实例绑定、每次 crop 增益 | 给出独立 KEEP/WEAK/BAD/UNRESOLVED 及逐步理由 |
| 导出/CPU/mask | 入选完整原始路径 | 任务唯一、单原图、文本与视图顺序一致、预处理不截断、监督位置 | 格式与监督信号可用，不代表学生会读清或学会 |

V2 基线 5,378 条均有本版逐图审核记录，其中 382 条复用近期源 hash 一致的实际看图记录，其余 4,996 条新复核；V2.1 的 37 条与 V2.2 的 88 条均有新逐图记录。多位 Codex 并行审阅者不等于多个独立模型族。补充批次先原图盲答再审路径；基线并非全部采用这种盲答流程，也并非每个前缀都单独隔离给裁判。

本版最终 4,040 条中，3,948 条可关联历史审查意见：Sonnet 5.5 3,564 条、Opus 5.5 380 条、Sonnet workflow 批次标注 4 条。另 92 条没有关联历史详细意见（基线 5 条＋新补充 87 条），但具有本版 Codex 逐图结论。历史模型名称保留原记录的归因，不能用批次名称代替逐调用回执核验。网页将历史意见与最终标签分栏展示。

| 标签 | 本版含义 | 是否进主集 |
|---|---|---|
| KEEP | 关键事实/绑定可靠，原图充分或每次 crop 有实际证据作用，完整路径可模仿 | 是，仍需过 CPU/导出门 |
| WEAK | 可能答案正确，但存在无增益复看、低效步骤、表述/依据不够严谨等问题 | 否 |
| BAD | 明确关键事实错误、错绑对象、无据断言或错误过程 | 否 |
| UNRESOLVED | 图像、指代、题意、知识或可回答性无法可靠确认 | 否，不能默认算对 |

## 11. 网页内容与复现

公开网页包含 **全部 4,040 条入选完整可见轨迹**，以及 **5,503 条过程审核记录**的四档标签、判由、生成器、历史审查意见、步数和证据索引。没有入选的 1,463 条仅列审核记录，不冒称全部展示了它们的原始完整路径。

公开版不分发第三方图片或原题全文，不包含接口回执、访问凭据、本地源文件路径及隐藏推理。合法持有本地数据时，可以打开同一界面的看图版：查看每条的原始任务、实际原图及所有返回 crop，共 7,047 个视图位置。图片不拷贝进公开仓库，服务器只绑定 loopback。

```bash
# 在这个公开仓库内；不调用模型、不改冻结标签
python scripts/verify_trajectory_catalog.py
python scripts/build_trajectory_catalog.py

# 完整看图需要本地已冻结的 V2.2 导出及合法持有的源数据
python scripts/serve_trajectory_catalog.py \
  --workspace-root /path/to/icml \
  --dataset-dir /path/to/icml/obs/benchmarks/sft_v2_2_keep_20261009 \

# 打开 http://127.0.0.1:8000/?local=1
```

六份既有 JSONL 是网页统计的冻结输入，hash 记录在统计 JSON；网页 JSON 分片另有 manifest。构建脚本只读已公开文本，显示层统一 Caption 标签；验证器核对计数、每题一条、每步视图次序、完整文本对应、四档汇总及所有文件指纹。LLaMA-Factory 原样导出及监督 mask 的依据沿用已完成的本地 CPU 报告，本次网页制作没有重新运行模型或训练。

## 12. 当前质量、局限与停止点

现在可以准确说：**4,040 条最终路径均已审核且满足本版明确的过程与工程要求；数量达到本次 4k 交付目标。** 本版不再接纳 WEAK，不再为了凑多步比例扩大生成。

仍然保留以下实际限制：

1. **模型审核可能误判。** 没有全体真人金标准；并行子代理不是独立模型族共识；历史审核配置也不完全一致。公开保留判由与指纹便于后续抽查。
2. **教师可读不等于 Qwen 可读。** CPU 处理器的图像像素预算可能继续缩小图片。已验证格式、长度和 mask，尚未逐图验证学生输入缩放后的关键文字/目标可辨性。这不应写成“已经证明适合 Qwen 学习”。
3. **覆盖有偏。** 定向选材偏向能审核清楚的样本，地图仅 4 条；极难、题意/GT 不清的题通常暂存。KEEP 率不可当作全池误差估计。
4. **恢复示范有限。** 诚实搜索失败及换区存在，但本版没有宣称独立 recovery 后缀训练集已完成。错误前缀不能轻率进主集。
5. **数量达到的是本次 4k 目标。** 它仍低于导师提到的后续完整学习常见 5k–10k 探索区间；当前无学习曲线，不能只按条数保证规模充分，也没有必要因此立即补生成。

下一步在训练条件就绪时核对学生实际视觉输入，再开始小规模训练与学习曲线检查。此刻交付止于冻结数据、网页、统计与审查溯源；旧暂停任务和生成监控保持暂停。
