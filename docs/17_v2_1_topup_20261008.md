**当前模型审核版：T 3,979 / Q 3,979 / G 3,629。** V2 的3,953条原样保留，新增26条K3完整KEEP路径；每题一条，无跨模型步骤拼接。数量仍未超过4,000，还缺至少22条新合格路径。本轮已生成部分已验收和导出，不扩大生成范围，不降低标签门槛。

这仍是**模型审核数据，不是人工金标准**，尚未训练学生，也未证明学生在自身输入分辨率下看得清所有证据。

K3客户端HTTP请求111次，全有回执，0技术错误。Gemini首题留下失败记录，111题未派发；服务容量错误及示范图读取不完整使本分支停止。本轮没有调用Astra或Claude，也没有重刷失败题。客户端调用数不能替代AGY内部服务端请求数。

K3实际收到的48题均来自旧WEAK池；BAD与UNRESOLVED修复槽分配给Gemini，尚未有效生成。不能把这次26条新增KEEP解释为已经修复了三类问题。

## 2. 审查规则与范围

生成结束后，先做CPU答案/协议筛选，再由4个Codex审阅者分队实际查看**37条候选、79张原图与返回crop**。四个worker是同一类审查系统的并行执行，不是四个独立模型族投票。新审核未提供GT或旧标签；每题先读原图、记录独立短答或不确定性，再查看整条路径。后者是完整路径回顾，不声称时序隔离的prefix盲读。

重点是当时可见证据、对象与属性绑定、首次确定性断言，以及每次观察是否有实际用途。原图充分的直答允许。定位后放大、恢复行列/单位、跨区比较、信息性排除、合理搜索未命中后诚实换区都可保留；无新依据的重复放大不收入KEEP。明确错误前缀不能靠终答正确洗掉。

这37条是经CPU选出的候选；26/37的过程通过率不能外推到所有库存。以本轮K3分配为分母，可收率是26/48（54.2%）。新标签与旧WEAK结论分开保存，没有覆盖旧标签或修改GT。

## 3. 它们教了什么

新增26条中，直答17、一次crop7、两次crop2。两条两次crop路径为T0014和T0016：分别核查小目标头盔细节、区分夜景车辆与遮挡，均有具体观察用途。它们是因证据需要入选，不是为了提高多步比例。

几个有代表性的拒收原因：

- **T0005 / BAD**：实际B♭5被持续读成A♭5；选对major性质也不能让错误读音前缀成为正例。
- **T0026 / BAD**：图形面身份、相邻关系和T朝向存在关键错误，未有效修正。
- **T0032 / BAD**：手套与人绑定可读，但人物朝向及选项排除逻辑错误。
- **T0013 / WEAK**：船只数量有据，后两次重复放大没有补充证据。
- **T0020 / UNRESOLVED**：00:04:00读数正确，但截图不能确认它是总时长还是播放进度。
