# 从“少裁图”到“读对却答错”：目前究竟测到了什么

2026-10-22。给导师的阅读入口。历史结果核对到 `f2ed44f`；本次整理已有代码、两批看图记录及第一次分段价值诊断，不新增训练或 GPU 测量。

**目前没有证据证明某种新的信用分配方法已经有效。我们确认了两个更具体的问题：原来的小额裁图代价可能被 advantage 的归一化放大；部分轨迹已经写对事实，却在绑定、选项映射或最终答案处出错。第二个问题值得测，但第一次分段价值诊断受到前缀切分和对照句的干扰，还不能据此决定训练哪一种方法。**

建议先读第 1–4 节；病例、可重算数字和代码分别在第 5–7 节。历史 card 和实验编号留作溯源，不再用它们代替问题描述。

## 1. 导师的两条建议，分别在问什么

最终目标没有改变：在尽量保住答题分数和 recover 能力的情况下，减少无效裁图与过长轨迹。裁图次数、生成 token、耗时是不同的效率指标；错框后的分数也不等于“按不确定性自主 recover”的能力。

**第一条是检查更新信号的尺度。** 对同一道题采样多条轨迹，最终奖励为 `r = 答对 × (1 − λ × 裁图数)`。GRPO 再减组均值、除组内标准差；RLOO 则减去其余轨迹的平均奖励，不除标准差。导师要求 λ=0/0.01、其余条件相同，是为了先看这个区别是否导致异常行为。

这里有一个可直接推导的现象：若一组全答对，`r_i = 1 − λN_i`。忽略数值稳定项且裁图数有差异时，GRPO 的归一化优势变成 `−(N_i − 平均N)/std(N)`，λ 被约掉。原本想施加的“小额代价”，未必仍是小信号。RLOO 中这部分仍与 λ 成比例。这解释了为什么要先做干净对照，而不是立刻再加一个奖励项。

**第二条是检查信用落到哪里。** 一条轨迹里可能先看对，再答错；也可能裁图没得到新信息，最终却答对。把整条轨迹同一个 advantage 交给所有生成 token，无法直接指出哪个片段有帮助、哪个片段造成损失。导师提出的四种情况是希望区分这些作用。仅凭前后两个探针的对错，还不能把“对→对”认定为冗余、把“错→错”认定为必要探索。

这两条不是互斥解释：advantage 是信用进入更新的载体；需要分清**信号尺度、价值估计、token 分配及最终优化目标**。

## 2. 已完成的测量，怎样一步步缩小问题

| 要回答的问题 | 实际比较或检查 | 看到的结果 | 对下一步的约束 |
|---|---|---|---|
| 小代价为什么把策略推成全直答？ | GRPO/RLOO；λ=0/0.01 | GRPO λ0.01 曾塌缩，RLOO λ0.01 没有；RLOO 的裁图数仍没下降 | 归一化是有代码推导和运行对照支持的解释；还未解决效率。历史塌缩 run 与 RLOO 并非同期严格配对，不能称所有因素已排除 |
| 决策点基线能否提供更好的信用估计？ | 在决策点分叉“现在就答”；检查信用系数二阶矩与分叉协议一致性 | r1 第40步门槛未过，第160步通过；没有训练 | 二阶矩不是梯度方差，一致率不是方法收益；不能把门槛失败写成方法失败。纯状态基线本身也不新增惩罚冗余工具的目标 |
| 手写规则真的区分导师的四种情况吗？ | 穷举前后标签与 advantage 符号 | 改变裁图后标签不改变输出，实际只分两格 | 停用这个实现；不要把它当“四格方法已经试过” |
| 是否存在“新细节有用，但最终错了”的病例？ | 40 个焦点状态，逐图比较真实回执 T 与已有视图裁出的 C | 严格0、宽松1，低于事先8例门槛 | 本批材料不能检验“保护获取新细节”；未运行该配对回执 GPU 诊断，不是否定方法 |
| 是否存在“事实已经写对，后面却错”的病例？ | 文本规则挖掘，再对另一批40例/129张输入视图逐图审阅 | 9例较清楚、4例混合、27例排除或暂缓 | 存在性成立到模型审阅层级；主诊断9例中7例需在同一轮内部切分 |
| 正确事实是否提高后续答对概率？ | 13例 × 4前缀 × 16续跑；权重冻结 | 错误前平均答对概率约.53；事实句相对替换句的增量约−.13，区间含0 | 原定进入 RL 的条件未满足；控制句和切点仍有混杂，先修测量 |

训练对照的关键数字只保留一组：第160步 E1，GRPO 重跑 **.648 / 1.94次裁图**，RLOO λ0 **.652 / 1.93次**，RLOO λ0.01 **.663 / 2.08次**。这些数说明“未再塌缩”并不等于“学会少裁图”。单种子且准确率差值区间跨0，不据此宣布准确率提升。完整 benchmark、E2、训练成本及重叠风险见 [docs/34](34_report_for_mentor_20261022.md)。

另一组价格通道+非对称采样曾减少平均裁图（见 docs/27、34），所以不能把“这些 RLOO 对照没减少裁图”扩写成“历史所有 RL 方法都没减少裁图”；平均裁图次数与首轮是否直答也不是同一指标。

## 3. 先看三个病例，再看平均值

### 病例 u39：读到 $100，却选择了 $700 的选项

[完整轨迹与标注](../data/review_20261022/utilization/u39.md)。学生在第2轮写出 Employee 1 的 Total Pay 是 **$100.00**，随后映射到选项 A；对应正确金额的是 C，A 是 $700。这是一个具体的选项映射错误，不需要再用“可能没看清”来解释全部过程。

但测量出现了警报：事实句末尾续跑答对 **2/16**，决定性错误之前续跑答对 **16/16**，两个原始文本前缀只差尾部空格。不同前缀用了不同采样种子，且没有验证原生成 token 前缀，因此目前不能把这14次差距归因于“推理突然变好了”，也不能单凭它把旧错误定性为偶然失误。它首先说明这个测量对前缀构造非常敏感，原因仍需核对。

### 病例 u28：全图关系正确，后面混用了局部坐标

[完整轨迹与标注](../data/review_20261022/utilization/u28.md)。第1轮写出全图中摩托在左、狗在右；后面描述局部裁图中的狗在左下，又据此比较全图中的位置。可见文本支持“不同视图的坐标没有正确绑定”这一错误描述，但不能直接读出模型内部因果机制。

这个病例在写事实那轮开始前已经 **16/16** 答对，写完事实后 **15/16**。原图已在上下文中，重新写一遍事实不一定还能增加答对概率。因此，“价值没上升”并不证明模型不具备利用证据的能力。

### 病例 u17：caption 一直正确，最后字母错了

[完整轨迹与标注](../data/review_20261022/utilization/u17.md)。同一轮正确写出 EUR 占 **50%**，最终却输出代表10%的 A。事实后续跑 **16/16** 答对，答案前续跑 **4/16**。这是值得定位到答案生成处的病例，但还需排除切点构造造成的影响。

已经输出错误答案后的奖励0是终局事实，不能拿“0减错误前价值”当作独立测出了价值下降。它可以用于构造优势估计；是否改善训练，需要另做对照。

## 4. 第一次分段价值诊断到底测的是什么

固定某一条旧轨迹的前缀，保持对应历史和图像，让**生成这条轨迹的策略**重新完成任务16次。`V(P)=这16次最终答对的比例`，不是模型口头置信度、不是一个已训练好的价值网络，也不是验证过的工具因果贡献。

| 前缀 | 实际构造 | 它能回答什么 / 混入了什么 |
|---|---|---|
| P0 | 写事实的那一轮开始之前 | 从该轮起重新做，能否答对；不是紧挨事实句前，可能也移除了句前其他内容 |
| P1 | 保留到正确事实句末尾 | 给定这段文字后继续做，能否答对 |
| P1c | 将事实句替换为固定一句话 | 比较文字替换的影响；替换句含“继续仔细看再决定”的动作倾向，并非行为中性 |
| P2 | 保留到决定性错误之前 | 在这个构造的前缀上继续做，是否仍有成功机会；不能仅凭旧错误推断该状态必然失败 |

主诊断为5个 SFT 病例、4个 r1 病例；另4个混合病例单列。温度0.7、总裁图预算8、每次生成上限640 token、上下文上限11264。总计 **832次续跑，0次参数更新**。正确率 `Y` 与带裁图成本的 `R=Y(1−.01N)` 均存入逐次结果；报告的主要价值是 **Y**。N含前缀已有裁图，生成token只统计新续写，不能把它直接当作全过程成本。

主诊断9例，按病例配对做2000次 bootstrap：

| 测量量 | 结果及95%区间 | 朴素解释 |
|---|---|---|
| 错误前价值 `平均V(P2)` | .528 [.292, .771] | 这些构造前缀平均仍有成功机会；不是所有失败都不可挽回 |
| 事实对替换句 `平均[V(P1)−V(P1c)]` | −.132 [−.444, .111] | 没有获得事实句带来正增量的证据；也不能排除正增量 |
| 写事实前后 `平均[V(P1)−V(P0)]` | −.083 [−.250, .076] | 本次没有稳定的平均上升，且不是只改变事实内容的干净比较 |

**必须区分规则判定与科学结论。** 事先规则把“S2区间含0”划入竞争解释成立，Open Scientist 第018步据此记录了相应判定；这份历史记录保持原样。但统计上，未检出正效应不等于证明没有效应，更不等于“信用分配机制已被否定”。本轮可靠的决策含义是：**进入新 RL 的条件没有满足，当前测量不足以区分机制。** 不应把记录字段 `mechanism_refuted` 直接写进论文主张。

## 5. 现在的问题清单：每个问题对应一个最小核对

| 问题 | 已有证据 | 下一次测量前应核对什么 |
|---|---|---|
| “中性”对照改变了策略 | 替换句要求继续看；核心9例中8例相对P1裁得更多，文本更长 | 保留句子角色和动作结构，检查替换是否只改变所关注事实；不能因换成遮词句就默认中性 |
| 字符切点不是原生成 token 前缀 | u39的2/16与16/16；5例P1/P2仅差空格 | 保存并核对完整prompt token IDs、切点、图像顺序和历史；同一token状态应复用测量，记录种子。单独重编码助手文本也仍需验证与原上下文的边界一致 |
| 原图已提供事实，价值可饱和 | 9例中4例P0≥.875 | 报告基线价值与上升空间；区分“再陈述没有增量”和“不会使用图像” |
| 失败样本选择与少量续跑 | 这是挖出的错题候选，主诊断只有9例 | 不外推失败率，不把SFT/r1病例差异解释为训练效果；置信区间需承认每个前缀有限采样的不确定性 |
| bootstrap只重采病例均值 | 汇总代码对9个已估计差值重采样 | 当前区间不是完整的两层不确定性评估；每格16次、二项标准误最大约.125，不能把点值当真值 |
| 原始续跑留痕不完整 | v1代码只输出y/crops/r/token数等，不保存生成文字、prompt IDs或具体失败原因 | 下一版保留可追溯前缀和逐次可见续写、解析结果、停止原因；本次不能从832行数值补造832条文字轨迹 |
| 科学目标仍有缺口 | 没有训练分段优势；recover尚未按不确定性定义评测 | 测量修好后再决定一个方法对一个基线；最后回到准确率、裁图、token与recover共同评价 |

本次读取时，已有第019步“修测量”的准备代码：token切点、局部遮词、相同前缀识别。它是后续工作的准备，不包含在这份 v1 结果里；本次不代替执行者启动或判定该批次。即使新版通过，也只说明具备进一步实验的依据，不能直接说明训练一定获益。

## 6. 代码、轨迹、标注怎样对应

- [分段锚点](../data/review_20261022/segment_boundaries.json)：13例；字符锚点与源轨迹逐字核对，但不冒称已验证原模型token边界。
- [v1逐次结果](../logs/mve/segval_v1/README.md)：832条逐次测量记录，可重算汇总；不是832条完整续跑文字。
- [代码入口与复核命令](../pipeline/eval/mve/README.md)：审查、构造对照、挖掘、审阅页面、分段测量、汇总、发布和验证。

沿用仓库既有数据边界：公开caption、动作、标注及索引，原图/回执图和题库原文不随本次发布分发。合法持有源数据的读者可以运行审阅页构建代码重建图像；没有图像时只能复核文本逻辑、标注一致性和数字，不能声称独立完成视觉复核。

审阅者是 Codex 模型，非人工gold。第一批s00提前见到标签；第二批在记录观察后揭示参考答案，但旧续写和最终答案本来可见，故不是完整盲评。病例中的`<think>`是该实验协议对外输出的短caption字段，并非另行导出的隐藏推理。

## 7. 给导师的简短汇报

我们先按您建议检查了 advantage：取消组内标准差后，小裁图代价不再伴随先前的全直答塌缩，但裁图效率没有改善。随后没有继续堆奖励，而是检查哪些步骤应得到信用。第一批40个裁图状态没有找到足够的“必要新细节但最后失败”病例，所以暂停了那条测量；第二批确认了9个较清楚的“写对事实、后面答错”病例和4个混合病例，具体错误集中在选项映射、行列/空间绑定及目标偏移。

我们对这13例做了冻结参数的分段续跑，但第一次测量受切点和对照句影响，尚不能用来证明某种信用分配方式更好。下一步主力应是让这个小测量能够区分“事实内容的作用、答案映射失误和前缀构造干扰”，再决定是否做一组短RL对照。当前没有方法收益结论。
