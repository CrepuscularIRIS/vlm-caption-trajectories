## 1. 这种观察—动作粒度，是否就是我们要的 SFT 教材？

对照 C01（原图足够，一步直答）、C02（相同数值下仍检查图表系列）、C03（保留原图行人事实，另看卡车）。我们想优先教实例/属性绑定、主动补足区分证据和适时停止。**这样的短 caption 是否信息足够、表达自然？C02/C03 是否需要显式 HOLD/REVISE，还是语义上做到即可？**

建议：保留足够好的直答与语义 keep，不为标签频次改写轨迹。若需要特定更新语法，另外挑自然产生且通过核验的完整示范。

## 2. 正常轨迹和恢复教材的边界怎样划？

C04 在两次无效 crop 后正确换区域；C05 的末步明确修正早期错误读数，但前缀有无据断言。**C04 补审通过后能否作为整条正例？C05 应整条排除，还是另作恢复数据并仅监督有效后缀？**

建议：不能因为最终答对便把确定错误的前缀当 clean SFT 标签。恢复池、前缀 mask 和依赖撤回的导出策略目前尚未实现/验收；保持讨论与已交付分开。

## 3. 当前多模型审核够不够？哪些样本需要多生成器共识？

当前为 Luna 生成，Sonnet 审结构/绑定，Gemini 或 Grok 按前缀盲读；不是三家完整评委投票。首版自动候选 1,241 条中，734 条另有家族轨迹过 CPU 门，但尚未核实其对象和关键事实一致；新增候选未沿用这一覆盖数。**是否接受该主流程，把生成侧对照优先用在绑定、修正和争议案例，而非每题强求三家生成？**

建议：先补 81 条 fallback 漏审、C03 上下文包、C06 坐标门，以及人工校准；多加评委不替代这些具体检查。

## 4. 多模型都与金标冲突时，怎样分辨共同盲点与题源问题？

C07 可能是把局部两行推广成总数；C08 需要核定“拖鞋下面”的范围；C09 四个模型读 5、金标给 6，需要核绿色激光与刻度的位置关系及遮挡。**这三类分别应如何标记：证据不足、共同失败、题意歧义、金标待核？金标更正需要什么独立依据？**

建议：保留原金标与评分，另设争议记录；不能多数投票改 gold，不能把“按金标全错”都称为已确认视觉错误。四个生成模型涉及三个家族，且没有声称所有可用模型都参与了这些题。

## 5. 首个可交付版本的验收线与后续验证重点是什么？

最新有 1,317 个自动候选、1,193 个图组；新批次人工终裁和最终预处理尚未完成。**能否先接受以绑定/主动观测为主、含直答对照的小版本，再补保持/修正/恢复？人工抽检发现什么问题必须退回整层，什么问题允许定向排除？**

建议：先定可操作的批次接受与排除规则；后续学生验证优先测对象—属性/读数绑定、主动获取区分证据、无据断言，答案准确率同时报告。没有用“回退词更多”代替训练收益。
