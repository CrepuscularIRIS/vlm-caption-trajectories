# 从首轮动作实验到后续裁图：工程与建模教训

2026-10-23。Codex 审查与设计输入；不是新实验结果或导师已批准的方法。输入固定为公共提交 `5399cba`；不启动 Stage 1、不占 GPU、不改 CC 的 study。

## 先说结论

Stage 0 足以支持按原 READOUT 停止首轮小头方案，但不是证明“任何首轮改进都不可能”。用户真正希望减少的是**第一次之后的冗余裁图，同时保住答题与恢复能力**。下一步要先证明后续状态存在可辨认、可学习的停止空间，再讨论如何给损失。

## 导师的思路不是“遇到问题就加一个 loss”

| 问题 | 导师提出的操作 | 它能区分什么 | 不能顺便证明什么 |
|---|---|---|---|
| 裁图成本一加就全直答 | 固定 SFT 与其他设置，RLOO λ=0/.01 | advantage 缩放是否造成优化异常 | 不再塌缩不等于学会少裁图 |
| 最后答对却把所有动作一起奖励 | 区分有效、冗余、失败探索、误导工具；问哪些 token 收信用 | 结果奖励应如何落到局部行为 | 一次成功或失败不能直接确定工具因果贡献 |
| 希望先具备预期动作行为 | 同前缀两路续跑，直接约束动作选择 | 选择路线是否比原策略更好 | 全局直答率变化不等于按状态选择 |
| 后续更细的信用分配 | 提到势能方程、分段优势 | 中间价值变化如何归因 | 未给出完整边界、终止处理、损失与实验证据 |

这条链是：**把期望行为明确到决策对象 → 设计对照测量 → 找到可改变的信号 → 再决定优化谁。** 本次“后续是否继续裁图”是用户明确的新聚焦，不能说导师已批准某个后续轮算法。

## 必须分开的四层

1. **Reward** 定义想要什么：现用 $R=Y(1-.01N)$，错误轨迹没有裁图成本项。提高 λ 是改变目标，不能充当修复信用分配的默认动作。
2. **Advantage** 决定相对谁、按什么尺度更新：RLOO 去掉组内 std 后不再塌缩，支持缩放问题的诊断，但不能自动制造停止信号。
3. **Credit routing** 决定哪些 token/动作接收何种学习信号。只有动作无关的合法基线才能在相应假设下保持期望梯度；只在选中裁图时减信用会改变更新估计，未必对应清楚的新标量目标；不能冒称是零期望 baseline（Pro 复核后的精确化）。有限采样、PPO 裁剪、归一化与参数共享另需检查。
4. **Auxiliary decision loss** 直接教选择路线，改变总训练目标。只给动作 token loss 仍可能经共享参数改变 caption 与作答；全局偏移不能归因于单一“饱和”原因。

## 这几轮应留下的具体教训

- **先做空间检查，再写新头/新 loss。** Stage 0 用既有分叉阻止了低收益首轮设计，是有效停止。不能把停止解释成整个信用分配方向被否定。
- **四格公式要做真值表。** 改裁图后标签却输出不变的规则，只用了前置两格；名字写“四格”不够。动作相关基线也不能冒称无偏。
- **明确动作发生的时序。** 发出裁图那轮的 caption 位于自己的回执之前，含旧证据利用，不能当成纯获取动作；后续 caption 又可能已承诺 WORD/路线。
- **合法分叉比公式优先。** v5.2i 只放松第 1 步 WORD 与动作绑定；第 2 步起沿用 v5.1。直接在后续 caption 后强插相反动作会混入格式错误。要选择合法共同前缀，或把协议改变作为显式变量并提供匹配对照；别偷偷推广首轮豁免。
- **强制分叉和自然行为不是同一个量。** 两个动作 stem 的归一化概率不是全部自然解码的动作概率。prefix 必须只依赖当时历史，不窥视下一 token；图像、processor、tokenization、剩余预算及强制 stem 都要对齐。
- **一个 checkpoint、一个标签策略。** 240 个训练状态来自变化中的策略，不能冒充固定参考模型的额外 240 题。题内多个状态/重复题应聚类；反复开发的 E1 不能继续称封存测试。
- **公平对照要保留已有能力。** 与原分数最佳阈值比较比全局常数更强；但阈值也须 train-only 选择。四格与零信用同时改变平均激励时，差异不能全归给“信息”。
- **门槛必须 fail closed。** step-1 gate 未运行却训练到 step 8 是执行偏差，事后通过不抹掉偏差。缺环境变量要启动前检查；重跑评估、失败调用和 fork 成本都入预算。
- **价值不升不是能力不足的充分证明。** 冻结策略的续写值受分叉协议、可见输入、采样精度与续写策略共同影响；不能由单个无增益结果断言所有信用设计都无用。先列竞争解释与可区分它们的最小观察。
- **结论等级不混用。** CI 包含零不是等价；全局 D 可靠不等于边界状态可靠；少裁图且准确率区间很宽不能称准确率不下降。参考模型/Pro 的判断都不是人类金标或效果验证。

- D 平均 −.468125 = accuracy −.4765625 + cost .0084375；同表 oracle 超过最佳阈值 .0081640625。
- 5 个 D>0 状态中，参考 z>14 的只有 **2 个**（Math_492、Biology_60）。第三个 z>14 的 Agriculture_22 是 D=0。原 README 的“3 个”应读为“2 个”；不改变停止决定。
