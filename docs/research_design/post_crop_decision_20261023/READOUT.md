# 读解：下一阶段先研究“什么时候可以停”

2026-10-23。Pro 已完成答复；[完整原文](PRO_RESPONSE.md)、[发送提示词](SENT_PROMPT.md)、[回执](RESPONSE_RECEIPT.json)。本轮完成 CPU 复核、工程总结和设计咨询；没有新采样、训练或共享 Open Scientist study 写入。

## 主力应转向什么

**保留首轮 Stage 1 的停止决定；把问题收窄为：第一次真实裁图回执之后，模型是否存在尚未利用的停止机会？** 现在优先完成这项测量的定义与材料核查，不直接开下一组信用 loss。

这张主卡分三层：

1. **有空间**：现在停比继续更省，而答题与必要恢复不受损；原模型尚未利用它。
2. **能识别**：只凭此时真实可见信息，能区分该停与该继续，优于原分数的简单阈值。
3. **能学会**：把信号写回原模型后，自然生成真的改善，不靠外部控制器替它决定。

目前后裁状态的这三项都未通过。这个研究价值来自可验证的问题，而不是换了一个公式。

## 导师的思维，换成人话

先用 RLOO 对照查“更新尺度是否把训练搞坏”；再问“哪些局部行为值得奖励”；直接动作监督则是把预期行为落实到一个明确决策。它们分别涉及优化器看到的信号、局部信用和行为约束。**先确定要改什么行为及如何测量，再决定损失给谁。**

首轮实验失败并不等于所有信用分配无效。之前把开始看、继续看、利用证据混在一起，会使一个指标变差之后很难知道到底否定了什么。

## 新卡怎样测

共同状态放在**首裁回执加入上下文后、下一轮尚未生成任何 token**的位置。保持模型与奖励不变：

| 路线 | 操作 | 测量含义 |
|---|---|---|
| S 停止 | 在 commit/abstain 的合法 WORD 路线内采样，生成 caption 与答案 | 现在结束取证的价值 |
| C 继续 | 在 locate/re_examine/fallback 路线内采样，再取证后允许原模型自然完成 | 包含必要多步探索的继续价值 |
| 自然参照 | 原模型未经强制的后续轨迹 | 原模型是否已利用上述机会 |

WORD 的组内比例来自冻结参考模型；后续 caption 可以不同。因此测的是**路线价值差**，不是某张 crop 的纯视觉贡献。后续 WORD 原本绑定动作，不能直接套用首轮 caption 后强插动作的代码。

同时看 $D=Q_S-Q_C$ 与 $T=Q_S-V_{nat}$：前者说明停止相对继续如何，后者说明相对原模型还有没有收益。不能把规范 header 分数当成自然动作概率。

## 候选损失是什么，尚未解决什么

若测量支持，Pro 提议直接作用于原 LM 的完整 WORD 路径，不加推理时小头：

$$
L_{dec}=\frac1B\sum_i e_i[-\widehat D_i p_\theta(h_i)+\tau KL(q_\theta(\cdot|h_i)\|q_0(\cdot|h_i))].
$$

$q$ 覆盖五种 WORD，$p$ 是停止两种 WORD 的总质量。用收益差推动合适方向，用 KL 限制对原分布的偏移；保留原任务 reward，但新增训练 surrogate。它不是 RLOO baseline 的无偏替换。

人话是：**确实值得停才往停的方向推，值得继续就反向推，同时尽量保留原有选择分布。**

单状态自由优化时，$p^*=\sigma(\operatorname{logit}p_0+\widehat D/\tau)$；这是有条件的解析关系，不是共享神经网络的行为保证。Codex 核对了 KL 恒等式、标量梯度和历史成本算例，[数值自查](ALGEBRA_CHECKS.json)与[代数说明](ALGEBRA.md)可查。没有运行模型梯度或验证实际优化。

仍有三项风险：极端概率处梯度仍小；共享参数会影响 caption 与答案；五条规范路径总概率可同时下降而归一化 KL 不变。最终必须检验 base 的自然输出，不能只看五类分数拟合。

## 下一步最小工作包与尚未冻结的部分

**当前建议只做零 GPU 状态清单与协议核查。** 固定实际参考 checkpoint，按题/图像组预选自然轨迹槽位，核对首裁后 token、图像回执、环境、预算与版本能否重建；记录可到达率和后续成本。不得根据最终答错、后面多裁图、caption 命中答案来选样。已有文本记录不等于完整输入可重放，详见 [LESSONS](LESSONS.md)。

Pro 的条件化预算为：最多 64 题组（建议 48 clean、16 错框），S/C 各一次，128 条新 suffix；0.40M 生成 token、8M 处理 token、2 GPU 小时硬帽。**这些是提议，不是已授权执行或耗时保证。** 保留完整 C 续跑，不能为省预算砍掉 recovery。

K1 仅适合便宜否证。即便理想化两路成功率都 .5，64 题准确率差的续写噪声近似 95% 半宽也可达 .173；实际分层/评价集更小，不能由此宣布严格保准确率，也不能生成可靠逐状态标签。

这份答复还不是可直接开跑的 PREREG，须补齐：

- 实际唯一参考 checkpoint、输入可恢复清单、自然 suffix 的同策略身份；“固定 SFT-A”指固定起点，不可混用 SFT 与 r1 估值。
- “足够空间/明显伤害”的具体效应阈值、题组划分/种子、阈值选择目标与并列规则、统计量及缺失处理；不能看结果后补定义。
- **recover 的不确定性定义仍缺。** 错框条件成功率可作压力测试，但不等于导师要求的“在不确定时主动恢复”；需另定当时不确定性的测量与校准，不能靠一次答错倒推。
- 若未来训练，需单独冻结 $\tau,\beta$、可训练参数、自然输出约束与候选更新拒绝规则；本次没有给训练放行。
- 分叉出现 invalid 应按原规则计分，不能丢弃重采来制造“合法 C”；公共采样温度、图像 token mask、完整 header 计分与预算需运行时核对。

## 卡库与近邻如何约束创新

主匹配为 **K19 的续写估值 + diagnose_then_target/C07 的诊断顺序**。K11 提醒按收益而非统一次数鼓励；K57 提醒区分取证与充分性，但外置 inspector 不符合最终自主目标。无需硬拼三张卡。

Codex 本轮额外核对两篇原文的相关方法段：

- [Stop-RAG v1 §4.1–4.2](https://arxiv.org/html/2510.14337v1#S4)：已有 STOP/CONT 价值控制及前缀多次作答；其继续目标包含未来最大值，与固定参考策略自然续跑的 Q 不同。
- [CAM-DF v1 §3、§5 Eq.6](https://arxiv.org/html/2607.27083v1#S5)：已有收益差符号/幅度加权的停止监督，但在工具执行前选择排名前缀，不观察工具回执。

上述为局部机制核验，非全文复现或全面查新。其余原文阅读清单仍为 Pro 自报。因此“学习停止”“MC 标签”“KL 约束”不能直接当创新点；待证贡献是后裁停止机会、可识别性和自主内化的证据链。
