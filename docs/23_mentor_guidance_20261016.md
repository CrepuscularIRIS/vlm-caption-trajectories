## 2. 逐条整理

**判断：**

| 导师说的 | 含义 |
|---|---|
| 整体结果正向；原始 A 已能教会有用行为，并支持后续 RL 提升 | 主线定为 A |
| GRPO 把主动观测搞得有点过头 | 对应报告第 8 节：直答 43% → 0.1%，原本直答对的题掉分 |
| B 让模型回到原目标，但收益不多；插值不必再扩大，也没有干扰梯度 | 不再扩大插值库；B′（只差一个变量的对照）不做 |

**要求：**

1. 从 A 的 SFT checkpoint 重跑 GRPO。
2. 先检查直答：模型看原图后直接作答，能否正常终止、正常打分。
3. 奖励里不给 hit / fallback 这类字面标签加分。
4. 不因为没调用工具而扣格式分。
5. 另跑一组带裁图约束的奖励：`reward = correct * (1.0 - 0.01 * crop_count)`。
6. 用同一个验证集，和原版 GRPO 对比。
7. 目标：减少无效裁图，同时保住答题和纠偏（recover）能力。

## 4. 下一轮实验

| | 原版 GRPO（已有） | 新一组 |
|---|---|---|
| 起点 | A 的 SFT checkpoint | 同一个 |
| 奖励 | `correct` | `correct * (1.0 - 0.01 * crop_count)` |
| 其他 | 165 步，同题、同划分、同超参、同种子 | 全部相同 |

- `crop_count` 取环境实际执行的裁图次数（预算 8，最多扣 8%）。答错仍是 0 分，所以只有答对时才体现裁图代价。
- 实现：环境已在计数，只需把次数写进每条采样的附加信息、打分时传给奖励函数，约 3 行；新代码放新目录，原版不动。另把每条采样的结束状态、裁图数、对错、得分逐条记下来。
- 对比用两组的同一步 checkpoint（上一轮保存到第 160 步）。

**0.01 会被 GRPO 放大。** GRPO 算优势时除以组内标准差（EasyR1 默认，上一轮也是这样）。一道题 16 个采样全答对、只是裁图次数不同时，分数是 1.00 / 0.99 / 0.98…，归一化后“少裁一次”的信号和“答对对答错”一样强。上一轮训练奖励均值约 0.65–0.75，这样的全对组不少。效果相当于：先保证答对，都答对时选裁得少的；在有对有错的组里，裁图代价几乎不起作用。风险是在本来就会答的题上被推向一次都不裁，纠偏变弱，由 E2 检查。先按导师的公式原样跑。
- 评测用上一轮的 552 题（440 题分层验证集 + 112 题 V\*），每题 4 次采样，温度 0.7；正常（E1）和首次裁图换错框（E2）两种条件都跑。

**要看的指标：**

| 目标 | 指标 |
|---|---|
| 减少无效裁图 | 直答率；平均裁图数；与之前某框几乎重合的重复裁图比例；“看清了还要再裁、把对的改错”的样本数 |
| 保住答题 | 总体与分层准确率；SFT 原本直答对的题在 GRPO 后的准确率 |
| 保住纠偏 | E2 中重裁比例、回到目标比例、扰动造成的净掉分 |

**预测与停止条件：**
- 预期：直答率回升，平均裁图数下降，准确率与原版 GRPO 持平（区间跨 0），E2 重裁比例仍接近原版。
- 若直答仍接近 0：查逐条记录，看全对组里直答是否真的拿到了最高分。
- 若准确率显著下降或 E2 重裁明显减少：代价伤到了需要裁图的题，下一步考虑只对“首轮已能读出答案”的情况扣分，或减小系数。

## 7. 第一轮结果：导师公式原样（10-17）

`reward = correct * (1.0 - 0.01 * crop_count)`，其余与原版 A 组 GRPO 完全相同。第 40 步验证准确率 .484，低于起点 .502（原版同步 .566），第 56 步停止。

**训练中的变化（每 8 步平均）：** 直答率 42.9% → 96.5%，平均裁图 0.92 → 0.05。训练准确率在第 17–24 步升到 .622（裁图 .38），之后跌到 .533。同一批里裁过图的采样一直比直答准，例如第 35 步 .90 对 .41。

**E1（552 题 × 4 采样，T = 0.7，取第 40 步）：**

| | A SFT | A GRPO 原版（第 160 步） | A GRPO + 裁图代价（第 40 步） |
|---|---|---|---|
| 总体准确率 | .552 | **.664** | .511 |
| 直答率 | 42.9% | 0.1% | **94.9%** |
| 平均裁图 | 1.01 | 2.31 | 0.08 |
| 平均 token | 161 | 276 | 69 |

| 层（准确率） | A SFT | 原版 | + 裁图代价 |
|---|---|---|---|
| D 直答 | .718 | .825 | .655 |
| O1 看一次 | .519 | .673 | .485 |
| O2 多次 / 纠偏 | .377 | .467 | .363 |
| H 难 | .206 | .263 | .256 |
| U 未标注 | .805 | .887 | .698 |

- SFT 原本直答且答对的 59 题，保持 .941（SFT .949，原版 GRPO .894）：“该直答的直答”生效了。
- 掉分集中在需要裁图的题上，几乎每层都低于 SFT 起点（只有 H 层略高）。
- E2 没法做：95% 直答，没有首次裁图可以换成错框。

**原因：系数被组内标准差约掉。** 一题 16 个采样全答对时，分数是 `1 - c·k`，GRPO 的优势为 `(r - 均值) / 标准差 = -(k - 平均k) / k的标准差`，c 消失。所以无论 c 取 0.01 还是 0.001，全对组里“少裁一次”的推力都和“答对对答错”一样强；有对有错的组里裁图代价又可以忽略。推力只来自全对组，再经共享参数扩散到需要裁图的题上。**因此单纯调小系数无效**；第 17–24 步的较好状态是训练途中经过的位置，不是某个系数对应的稳态。

文献里有同样的报告：Arora & Zanette（arXiv 2502.04463）第 5.4.1 节指出，长度惩罚在组内标准差归一下与系数无关，会导致准确率骤降；他们改用不除标准差的 RLOO 优势。Dr. GRPO（arXiv 2503.20783）也指出标准差小的题（全对或全错）被加了大权重。

## 8. 第二轮：奖励不变，组内标准差设下限

**做法：** 奖励仍是导师的 `correct * (1.0 - λ * crop_count)`；只把 GRPO 优势的分母从组内标准差改为 `max(组内标准差, 0.25)`。

| 组 | 优势 | 说明 |
|---|---|---|
| 全对 | `-4λ · (k - 平均k)` | λ 重新有意义：λ = 0.05 时每多裁一次约 −0.2（第一轮是 −1 到 −3.75） |
| 有对有错 | 与原版基本相同 | 16 个二值样本只要有一个不同，标准差就 ≥ 0.25，下限不生效 |
| 全错 | 0 | 不在难题上压制裁图 |

- 0.25 是 16 个样本里 15 对 1 错时的标准差，即二值对错奖励下非零标准差的最小值。
- λ = 0 时与原版 GRPO 逐项相同，所以和原版只差 λ 一个变量。
- 含义：一次裁图要换来大约 λ 的准确率提升才“划算”。
- 两组并行：λ = 0.025 和 λ = 0.05（4 卡各用 2 卡）。

**为什么不选其他写法：**

| 写法 | 文献 | 不选的原因 |
|---|---|---|
| RLOO / Dr. GRPO（不除标准差） | Arora & Zanette；Dr. GRPO | 对错项的尺度也变了，需要再跑一组“只看对错”的 RLOO 对照；模拟中纠偏率降到 .59 |
| 对错项归一、裁图项另加 `-λ(k - 平均k)` | CodeDance（arXiv 2512.17312）的拆分优势 | 全错组也会压裁图，难题上探索减少；约 30 行新代码 |
| 只罚超过组内答对样本最少裁图数的部分 | OTC（arXiv 2504.14870）、ShorterBetter（arXiv 2504.21370） | 优势本身已减去组内平均，再加基准增益有限，代码多约 30 行 |
| 只在组内有人直答答对时才罚 | Adaptive-CoF 的 AGAR（arXiv 2505.15436）、ALP（arXiv 2506.05256） | 方向一致，但需要按组判断；下限方案在全对组以外自动不起作用，效果相近且更简单 |

**模拟（玩具模型，方向性证据）：** 三类题——直答就够（D）、需要裁图（O）、首次常裁偏要再裁（R）；比例 .5 / .35 / .15，165 步，8 个种子。

| 方案 | 直答率（裁图决策不分题型） | O 题准确率 | D 题仍裁图（分题型） | R 题再裁纠偏 |
|---|---|---|---|---|
| 原版 | .01 | .83 | .96 | .92 |
| 第一轮（0.01，无下限） | **.90** | **.44** | .01 | .90 |
| 下限 + λ = 0.025 | .02 | .80 | .59 | .91 |
| 下限 + λ = 0.05 | .02 | .79 | .14 | .90 |

第一轮的公式在模拟里同样塌到 90% 直答，和实测一致。局限：题型比例与准确率是设定值，没有模拟 PPO 裁剪和 token 级效应。

**判定（与原版同步数比较）：**
- **塌缩，立即停：** 任一步直答率 > 60%，或平均裁图 < 0.3，或第 40 步验证 < .53（原版 .566，第一轮 .484）。
- **前 40 步有效：** 第 40 步验证 ≥ .55；多出来的直答集中在 SFT 直答答对的题上。
- **最终成功（第 160 步）：** E1 总体准确率 ≥ 原版 − 1 个点；SFT 直答答对的 59 题 ≥ .93；E2 纠偏（重裁、回到目标）≥ 原版 − 2 个点；token 和重复裁图减少。

预计 7–9 小时（两组同时，各 2 卡）。
