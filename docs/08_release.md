# 公开范围、来源与权利说明

本仓库为 2026-10-02 的研究设计与证据元数据快照。公开展示不等于已经完成训练集正式发布。

## 包含与未包含

包含设计整理、当前协议/提示词、七个 Python 阅读快照、标准库复算工具、汇总元数据、五条真实轨迹的可见短文本与动作。案例同时包含正例和未入池反例，不能把 `cases/` 整体直接作为训练正例。

未包含第三方原图及 crop、完整基准数据集、完整 API 请求/响应、私有 reasoning 字段、访问凭证、个人讨论原话、模型权重。公开案例保留来源 ID 与视图哈希；原图再分发条件尚未逐项核实，故本次不随仓库提供。

`image_files_exist: true` 是本地导出时检查的历史记录，不表示 GitHub 中存在相应图片。公开包无法完成独立像素核验；本地带图案例册仍可用于面对面审阅。

## 数据来源与版本

当前源记录的 benchmark 标识包括 `mme_realworld_lite`、`worldbench` 与 `vs` 系列；其具体来源版本应按上游冻结题目清单与各数据提供方说明核对。本仓库不重新授权这些来源内容，不把来源数据的许可范围扩大到公开包之外。

模型名称以运行日志标签原样记录，包括 `k3-256k`、`glm-5.3-flash`、`claude-sonnet-5-5`。这些是本地配置/回执名称，不是对外部供应商当前产品列表或性能的独立认证。

当前仅公开供阅读、审阅与验证，**尚未声明统一的开源许可证**。公开可见不等于对全部内容授予任意再分发或再许可权利。后续如选择许可证，应分别明确原创代码、设计文档、生成内容与第三方数据的适用范围。

本仓库用独立 Git 历史发布，不携带原工作区历史。文件哈希覆盖本次发布内容；源文件哈希用于追溯本地依据。设计正文是从原始 Caption 与 BundleAudit 整理的公开版本，阅读快照保留当前实际实现，历史草稿未全部堆入公开仓库。
