# V2 合并版：短证据 Caption 轨迹的选材、审核与交付

日期：2026-10-08（America/New_York）。状态：**逐图复核全部完成**。统计来自同一份冻结清单；没有新增生成、SFT或RL实验。

## 1. 本版到底交付什么

本版将V1已有选材与CC对剩余多裁图库存的审核结果合并，每个去重任务保留一条真实完整路径，不拼接教师步骤、不改写Caption或GT。最终主清单只收**KEEP且所有裁图都有实际用途**的路径；WEAK、BAD、UNRESOLVED、技术不合规与未完成复核均不进入主集。

当前主集可报告 **T=3953 / Q=3953 / G=3603**。若状态仍为进行中，此数只表示目前已符合门槛的子集，不是整批最终规模。T是完整执行路径，Q是图片—问题对去重任务，G是已登记原图组；均由同一清单计算，满足T=Q≥G。已完成数据审核/工程检查不等于训练已经发生，不能据此报告学生能力提升。

模型审核是本版实际验收依据；**不是人工金标准**。历史Sonnet/Opus意见与本轮Codex意见分别保留，旧标签不被覆盖。

## 3. Caption与构造思路没有推翻

仍采用Caption v5.1：每轮短证据描述＋一个真实裁图动作或最终回答。Caption写当前看到了什么、属于哪个实例/表格/行列、什么尚未确定，以及下一动作要解决的缺口。裁图参数在动作字段，不写成Caption里的坐标口述；保留真实图像回执、父子视图、源区域、显示尺寸与hash。

原四模型分别生成整条路径，Astra、Gemini、K3在历史定向补充阶段提供额外候选。强模型名、答案正确、答案多数一致均不能直接保证过程质量。共识可决定先审哪些题，但最终仍逐路径检查证据、绑定与行为。当前只从库存挑选；没有让新教师替全池重做，也没有新增场景专用协议。

本版是单原图任务；同一原图的多次crop仍属于单图。来源图数未核清的MMMU vision截图不因被合成一张图就获得资格。原生单张图表含多个panel则仍可纳入。

## 4. 选材与去重规则

1. V1沿用既有题级选材和来源记录；只有源结果hash与近期逐图记录匹配才复用复核。
2. V2只考虑Sonnet历史标签KEEP且`crops_informative=all_useful`的113条。WEAK全部不进主版本；部分无用的418条KEEP保留为储备，不偷换成BAD。
3. 去重键使用已有`canonical_sample_key`，合并原图—问题和已登记alias；不能仅用文件名、模型名或不同裁剪路径去重。每题最终一个result文件，禁止拼接。
4. 同一新增题多路径：先看证据与绑定分数，再看冗余、动作合理性、示范质量；同等时选较短完整路径，最后用稳定路径hash打破并列。没有“裁图越多越好”的奖励。
5. V1已有题的新增备选不自动替换，避免仅因更多crop发生无根据换选。此次新增部分是101个此前未收录任务。
6. G使用已有原图组归属；同图不同问题可以并存，但划分应以图组隔离。本版有301个主集图组含多题，不把它们算成新的独立场景。已登记图组不等于证明所有语义近重复都已找到。

## 5. 审查规则：KEEP不是只看终答

|结论|判定重点|主集处理|
|---|---|---|
|KEEP|关键事实、对象绑定、必要推算可靠；每次观察对决定有实际用途|协议和预处理也通过后收录|
|WEAK|核心大致可靠，但冗余、表述或过程存在弱点|本版全部排除，原记录保留|
|BAD|明确错读、错绑、虚构决定性证据或关键推算错误|排除；不靠改终答修补|
|UNRESOLVED|实际视图无法辨认、题意/目标歧义、题图冲突等|暂存，不改GT，不强行裁定|

“截图全部有用”按信息作用判断：可以是定位后看清细节、补回表头/行名、比较两个区域、排除候选、发现合理搜索未命中后换区。**不要求每次命中，不要求新像素，不要求显式HOLD/REVISE。**同一位置更合适的视图可以恢复可读性；反复框同一处且没有新增证据则不收。

原图足够支持决定时直接作答可KEEP，避免把学生教成每题必须crop。确定错误的定位或假事实前缀即使后来纠正，也不当整条干净正例；此类recovery单列，本版没有制作错误前缀mask或拼接恢复后缀。严格裁图标准是本版选材偏好，不表示导师要求所有历史轻微冗余的WEAK永久弃用。

审核者实际打开原图及所有返回crop，按`available_before`检查首次断言、引用和对象对应。本轮为完整路径回顾，审者看得到后续步骤；**不能称为上下文隔离的prefix盲读实验**。GT与历史评分不发给新的审阅代理，但问题/选项和轨迹终答可见。多个独立Codex上下文也不是多个模型族的独立投票。

主审对部分学科题查阅公开资料、对推算题做离线计算，并在逐条记录中保留`external_verification`。少数核对接触到了教材答案（例如F04075），另列`review_limitations`；不能把这些审核包装为纯盲答准确率实验。人工金标准和学生训练效果均未测量。

历史审核来源以原批次记录为准：Sonnet 5.5主要负责过程与绑定，部分补生成由Opus 5.5审查；版本/模型归属有些仅能到批次声明或抽检回执，不能称每条调用都重新核实了模型身份。逐条表保留原判由，并与本轮结论分栏。

合并候选中5372条找到了可关联的历史判由，另外6条仅有历史选材来源，逐条表如实留空；本轮逐图结论不因此省略。

## 8. 工程检查与公开范围

检查源路径与实际视图hash、单原图/训练划分元数据、动作时序、导出助手内容与原路径一致、图片顺序、坐标话和单think/action格式；不润色轨迹来通过检查。新增101条中13条触发既有协议硬门（10条坐标描述，3条输出结构），单列且不放行。模型过程KEEP不覆盖技术门。

这里的train是本项目冻结的内部划分，不等于上游数据集原始split一定叫train；数据来源包含公开benchmark任务。后续不能用进入训练的同题或同图组证明测试泛化，本版也没有运行这类评测。

LLaMA-Factory检查仅加载本地Qwen2.5-VL-7B tokenizer/processor，CPU执行，不加载训练权重，不占GPU，不训练。核对所有助手回合的labels、非目标输入屏蔽、图像占位数和16,384 token截断线；预处理通过证明可读入与mask正确，不证明学生看图能力。

另外从已生成缓存逐token核验全部5,378条：loss位置仅覆盖助手正文与终止符，解码内容和原始所有助手回合逐字一致，没有问题、系统提示或工具回执混入loss。配置为`train_on_prompt=false`、`mask_history=false`，即监督全部助手回合。

本次工程预检采用LLaMA-Factory默认图像预算589,824像素（768×768），小于部分教师收到的视图；全部候选中4,560张原图和1,685张crop尺寸超过此预算。**没有声称学生缩放后仍可看清全部细节。**以后确定训练分辨率时，需要保留与这些证据相容的显示尺寸，或对实际缩放后可读性单独核对；当前导出保留原始视图，不自行降采样或重写证据。

GitHub公开生成的完整可见Caption/动作、来源ID/hash、审查意见、统计与重构脚本。沿用仓库发布边界，不上传受限原图/crop、题库原文、隐藏推理或接口日志。合法持有源数据的本地环境可以重构完整ShareGPT训练文件；公开文本包本身不包含全部训练图片。

## 9. 能说什么、还不能说什么

- 能说：这一版做了指定范围的过程审核与去重；主集只保留最终KEEP、裁图用途可靠且通过工程检查的完整路径。
- 不能说：模型审核等于人工金标准；多审者可以消除所有共同错误；原图组hash保证没有任何近重复；未训练就已证明Qwen改善。
- 没有本轮重生成、重标GT、全量80K审核或新的模型公平对比。最终质量判定仍有误判可能，争议被保留而不是多数票改答案。
