## 一、一页人话：现在应当把主线收成什么

**主线应当是：模型已经开始观察以后，怎样减少没有必要的后续工具步骤，同时维持答题表现，并保留信息不足、裁错或需要核实时继续探索的能力。**

当前最值得做的研究判断，是让**已经启动的 λ 剂量对照先给出答案**：在现有 RLOO 和成功门控奖励下，把成本权重提高，能否得到可用的准确率—中间步数权衡。现在没有充分理由立即增加一个信用模块或势函数模块。

### 导师的问题是一条逐步排查链

结合公开指导，我的理解是：

| 导师追问 | 核心问题 | 已得到的回答 |
|---|---|---|
| 先查 advantage | 写进 reward 的裁图成本，经过优势估计后，是否仍是想要的尺度？ | 原 GRPO 在全对、长度不同的组内会约掉 λ；RLOO 避开了这个特定问题 |
| 再问四种情况如何分信用 | 一条轨迹最后答对，是否就应该给中间所有裁图同样的正向信用？ | fc、zero 已测，但没有得到兼顾少裁和精度的改进；这不能概括成“所有信用分配都无效” |
| 再试动作选择约束 | 即使有分支价值差，训练能否把它变成正确状态下的实际动作变化？ | 旧首动作实现未通过原定门；Stage 0 不支持继续投入原首轮预测头 |
| 再提势函数 | 能否给时间上的学习信号增加结构，同时说清是否改变目标？ | 严格 telescoping 在当前轨迹级 RLOO 中抵消；逐轮信号可能改变学习过程，但不会凭空产生效率偏好 |

这是一条缩小问题的诊断链，**不是要求把四种方法装进同一个系统**。docs/20 已明确要求把方法约束到小问题，避免同时堆信用分配、过程奖励和新优化目标。[公开指导与实验记录][d20][、docs/30][d30]

### 我们确实测过什么

| 已测事项 | 观察 | 现在能成立的判断 |
|---|---|---|
| 原 GRPO 加 λ=.01；之后设 std 下限 | 前者塌缩；后者显著减少裁图 | 优势尺度必须核对；成本可以改变轨迹长度 |
| 较强成本的旧组、卡 B | 步数明显减少，准确率点估计较低 | 有压缩潜力；**尚未证明精度非劣或 recover 无损** |
| 首轮 dV | 最终约多裁 1.7 次，首轮决策没有产生预期改变 | 该接法没有解决中间效率问题 |
| 干净 RLOO λ=0/.01 | 约 1.93/2.08 裁图，准确率约 .652/.664 | 不再出现原来的塌缩；.01 没有显示稳定的少裁收益 |
| fc / zero | fc 多裁约 .54；zero 少裁约 .31，但掉约 2.5 个百分点 | 一味压裁图轮信用可能伤精度；fc 未改善效率 |
| 首动作监督与 Stage 0 | 原监督按预定门判否；首轮新增选路空间很小 | 停止旧首轮路线合理，**不能外推成所有中间状态都没有空间** |

这些结果见 [docs/23][d23]、[27][d27]、[29][d29]、[30][d30] 和 [Stage 0][stage0]。

**目前仍只是推断的三件事：**

1. 后续轨迹里究竟有多少步，可以从**同一中间状态**可靠地省掉。
2. 当前瓶颈究竟主要是成本弱、停/继续选择不准，还是下一张裁图本身找得不够好。
3. 即使测到了局部可省空间，它能否被写回共享 VLM，而不同时压掉必要的 recover。

因此，现在合适的表述是：**已有减少中间步数的动机和若干效率信号，正在检验最简单的成本解释；尚未完成无损删步的因果识别。**

## 二、审查 docs/33：方向已经纠正，但几处结论仍需降格

### 2.1 先把四个问题分开

| 问题 | 实际改变的对象 | 当前 λ 剂量对照能否直接识别 |
|---|---|---|
| **代价力度** | 成功与裁图成本之间的奖励权衡 | **主要能回答这一项** |
| **给哪些 token 信用** | 同一结果信号怎样分配给 WORD、caption、框、终答等生成 token | 不能；当前 mask 和广播方式基本固定 |
| **后续停/继续选择** | 某个已收到工具观测的状态下，应立即作答还是继续取信息 | 只能观察行为变化，不能仅靠总裁图数确定判断是否更准 |
| **裁图定位效率** | 决定继续后，裁哪里、用哪个 source、取多大上下文，才能更快获得所需信息 | 不能；更好的框与更早停止都可能使总次数下降 |

当前奖励是

\[
R_\lambda=Y(1-\lambda N),
\]

其中 \(Y\) 是终答正确性，\(N\) 是环境**实际执行**的裁图次数。调 λ 保持了奖励形式，但**改变了成功与成本的权衡**，也改变成功样本相对失败样本的奖励间距；它不是一个纯粹的信用路由对照。[奖励实现][rewardcode]

而且，裁图次数与助手回合数需要保持口径区分：正常完整轨迹通常另有终答轮。无效、超限或过早结束造成的短轨迹，不能自动算效率收益。

### 2.2 “0.45、14%、0.78”应该怎样写

代码定义的是：对题目 \(q\)，从四次自然采样中取最短的正确样本，

\[
m_q=\min_{j:Y_{qj}=1}N_{qj},
\]

再对正确样本计算

\[
e_{qi}=N_{qi}-m_q.
\]

这里有三个需要修正的地方。

**第一，0.45 的分母不是“除去参照后的其余正确样本”。**  
公开汇总中，r1@160 的 E1 有 1,465 条正确样本，经验额外裁图合计 652 次：

\[
652/1465=0.445.
\]

最短样本自身的零值也在平均里。约 10.17% 的正确样本比本题经验参照多裁至少两次。[代码][excesscode]、[汇总][excessdata]

**第二，14% 是这个描述性统计量占全部裁图的比例。**

\[
652/4589\approx14.21\%.
\]

它支持“同题的成功轨迹长度存在可观差异”。它没有证明那 652 次裁图能从原轨迹的中间状态直接删除：

- 两条自然轨迹可能已经走到不同区域、形成不同判断；
- 短样本可能碰巧猜对；
- 某条长路径后面的步骤，可能正在修复前面已经发生的错误。

如果保留“下界”一词，只能限定为相对于某种**题目级存在性最短成功路径**的比较，不能称为“可靠可删步骤的下界”。我建议正文直接称它为**经验额外长度参照**，减少歧义。

**第三，E2 的 0.78 仍是相对 E2 自己的经验最短正确样本。**  
它不是 E2 比 E1 平均多出来的裁图数。公开汇总中的平均裁图约为 E1 2.078、E2 3.212，两者相差约 1.133；这些额外步骤中，多少是必要 recover，现有统计没有识别。[汇总][excessdata]

同理，“42% 的裁图出现在错误轨迹中”不能译成“42% 都浪费了”。失败可能发生在合理探索之后，也可能发生在很难恢复的状态。

### 2.3 “λ 只占 2–5%，所以问题只在力度”超出了代码支持范围

RLOO 的线性分解成立：

\[
A_i=\operatorname{LOO}(Y)_i
-\lambda\operatorname{LOO}(YN)_i.
\]

`ledger_diag.py` 计算的比例是

\[
\frac{\sum_i |A_{\text{cost},i}|\,T_i}
     {\sum_i |A_i|\,T_i},
\]

其中 \(T_i\) 是生成 token 数。这是**优势幅度乘 token 的代理量**，不是参数梯度份额。它没有包含 token 的 score gradient、参数间方向抵消、优化器预条件、裁剪或共享参数传播。[Stage A 代码及结果][stageA]

另外，公开表中的“全对组占全部信号不到 1%”使用的是未乘 token 的 \(\sum|A|\)，不能与另一列混成同一个“更新占比”。

`push_later.py` 的优势—长度乘积为负，也只能说明当前采样中的关联。实际更新后期望长度的变化还取决于类似

\[
\Delta\mathbb E[N]
\approx
\eta\,\nabla_\theta\mathbb E[N]^\top
P\,\widehat g_R
\]

这样的参数梯度关系。困难路径更容易失败、失败后多尝试，本身就可能产生长度与正确性的负相关。

还有一个代码口径细节：其 `noncap` 列去掉了部分乘积项，但没有重新计算过滤后的均值与分母，不能解释成“去除触顶样本后重新估计的条件协方差”。

**因此，建议将 docs/33 的结论改写为：**

> λ=.01 的显式成本在现有优势幅度代理中较弱，且自然轨迹存在成功长度差异，因此值得用更大 λ 做干净剂量检验；这些统计尚不能证明唯一瓶颈是力度，也不能保证参数更新会朝正确的中间删步方向移动。

这是解释上的收紧，不是修改正在执行的实验。

### 2.4 旧结果不能升级为“精度持平、recover 已保住”

旧 std 下限＋λ=.05 组，平均裁图从 2.31 降至 1.23，但准确率差约为 **−1.7 个百分点，95% 区间约 [−3.7,+0.3]**。这允许真实下降超过两点的可能性。原 docs/24 本身也将“保证答题”写为“未能确认”。[docs/23][d23]、[docs/24][d24]

recover 的旧指标也不是一致改善：例如再次裁图比例略降、回到目标比例上升，而“没再裁就答错”增加。它们支持“部分恢复行为仍在”，不足以证明恢复能力整体不受损。

卡 B 的准确率点估计是 .656，且：

- “−37%”对应原版 2.31 的参照；
- “−25%”对应重跑版约 1.94 的参照；
- 它同时改了价格通道与全错组处理，训练 GPU 时间也增加，不能当成纯 λ 证据。[docs/27][d27]

fc 相对 zero 的优势，同样不能全部归给状态信息：fc 的平均裁图信用约为正，zero 固定为负，**状态辨别信息与平均裁图激励强度同时不同**。代码实际把 fc 系数写到整段裁图轮 token，标量终奖没改，不代表更新估计器没有改。[fc 实现][fccode]、[第二轮 Pro 回读][pro2]

### 2.5 四个 checkpoint 有用，但回答的是学习过程

r1 的 1.89 / 1.99 / 3.49 / 2.08 是同一训练过程中的四个位置。变化可能同时包含：

- 真实学习动态；
- 轨迹分布迁移；
- 有限评测采样噪声。

不能一概称为“checkpoint 噪声”，也不能把四个位置当四个 seed。“至少 3/4 过线”可以作为既定的操作性稳定性要求，但不能解释成三次独立复现。[Stage A][stageA]

### 2.6 当前剂量对照能回答什么，回答不了什么

**能回答：**在当前起点、数据顺序、RLOO、预算和训练配方下，提高 λ 是否呈现可用的单种子剂量响应，以及这种响应怎样随训练推进变化。

**回答不了：**

- 哪一步从同一状态删掉仍然安全；
- 少裁来自更早停止，还是更好的定位；
- 什么 token 应该获得多少局部信用；
- 未覆盖的不确定情境中 recover 是否保持；
- 跨训练 seed 是否稳定；
- 科学意义上的非劣。

**原判读门保持不动。** 同一 λ 在至少三个 checkpoint 达到原记录的少裁要求，并满足原文 E1/E2 精度门，就按既定规则选为新基线；本轮不重写条件、不补改显著性要求，也不重新建议启动 .05/.10。[docs/33][d33]

但原门之后的两句机制推论需要分开：

- **过门**不意味着下一步必须加势函数或信用模块；
- **少裁但掉分**只说明该代价方案没有达到当前操作目标，不直接证明“根因就是信用分配”。

### 2.7 可以补充的探索性指标

我最建议补一个与本次目标直接对齐、且能从已有轨迹计算的分解：

\[
\mathbb E[N]
=
P(N\ge1)+\mathbb E[(N-1)_+].
\]

后一项是**每道题平均发生多少次第二次及以后的裁图**，使用全题分母。由公开 r1@160 E1 汇总可得，它约为 \(2.078-0.998=1.081\)。这是后续调用量，仍不是无效调用量。[公开汇总][excessdata]

它的用途是解释：总裁图下降，究竟主要来自少做第一次观察，还是确实减少了后续步骤。**它不替换原验收门，也不把提高首轮直答率设为目标。**

同时补报：

- E1/E2 的精度、总裁图、后续裁图、超限/无效终止、生成 token；
- 按题的“对→错”“错→对”和各 benchmark 的差异；
- E2 实际施加首次裁图扰动的比例，避免因更多轨迹没有首次裁图，而把较小的 E2 净掉分误读成 recover 更强。

只看正确样本的长度也不够：如果某些长轨迹变成答错，它们会退出“正确样本”分母，使这个条件均值看起来更好。

## 三、从 92 卡中只保留两条思路，推荐第一条的诊断用途

**即时建议仍是等待现有 λ 结果。下面两条是结果留下具体缺口后才考虑的方向。**

### 候选 A：在同一合法中间状态比较“现在答”与“继续裁图”

**主卡：[PC-F2-01][cardA]。** PC-F1-16 的兄弟分支估值、PC-F2-19 的先审信号，可作为实施参考，不是额外叠两个模块。

最近、最相关的已核查前作：

- **C3**：恢复同一完整记录状态，替换动作并真实续跑，以兄弟替代动作形成局部比较。其无偏性结论要求完整状态可恢复、替代动作独立采自行为策略，以及相应的采样条件；实验主要是文本 agent 团队，不能直接当作 VLM 裁图收益证明。[arxiv.org](https://arxiv.org/html/2603.06859v4?utm_source=chatgpt.com)
- **TWICE**：已经包含同前缀整轮替换、真实续跑、局部信用；还测试了带搜索成本的效用，并展示了中间“再次验证／现在回答”的案例。因此“中间反事实＋成本＋局部信用”已经有非常接近的前作。[arxiv.org](https://arxiv.org/html/2610.31544v1?utm_source=chatgpt.com)

**真正可做的差异**是把这一测量放到 VLM 的后续裁图边界，恢复正确的多图输入和坐标绑定，测量：哪些中间状态存在可靠的少步空间，哪些状态继续观察确实在保护 recover，以及这些差异能否以可接受成本被识别。

这首先是**应用改造与测量贡献候选**。当前不能包装成新的信用分配机制。

它比预算压缩更贴合本问题，因为允许同一题在不同中间状态获得不同结论：证据足够时停，裁错或缺信息时继续。但它仍只评估**指定继续策略**，不能证明当前策略之外不存在更好的下一张裁图。

**我的推荐：如果 λ 对照留下需要解释的中间决策缺口，先做这条的无训练诊断，不预先选新 loss。**

### 候选 B：按通过率收缩或分配预算

**主卡：[PC-F5-03][cardB]。**

- **PALU**：上一轮每题通过率达到阈值时，按正确回答长度的分位差缩预算；否则重置到最大预算。[arxiv.org](https://arxiv.org/html/2510.10168v2?utm_source=chatgpt.com)
- **IBPO**：依据长短模式的质量差，在批级预算约束下分配较长回答名额，再进行样本选择和投影更新。[arxiv.org](https://arxiv.org/html/2501.17974v2?utm_source=chatgpt.com)

迁移到裁图轮数仍然属于应用改造。它需要每题足够、近期的采样，并且清楚说明训练和部署各自受到什么预算限制。

**现在不推荐采用，理由很具体：**

1. 题目历史通过率不等于当前中间状态的 recover 价值。容易题的一次错误定位，也可能需要额外两步。
2. 缩预算改变了可行动空间和训练分布；观察到短了，可能主要是被截断，未必是学会了合适停止。
3. 四次采样中偶然出现的最短正确路径，不能直接当安全预算。
4. PALU 对旧通过率“偏保守”的解释涉及性能近似单调改善；本项目已经观察到明显训练动态，不能直接套用。

因此，两条中我选 **A 的局部诊断**；B 保留为备选。当前不增加第三条 PBRS 方法线。

## 四、若需要后续 probe：一个足够具体、但不启动训练的算法

### 4.1 合法中间状态 \(h\)

分叉点必须在：

> **某次工具返回已经完整写入历史之后，下一轮行为词 WORD 尚未生成之前。**

并且已经至少执行一次裁图，仍有继续裁图预算。

状态需要恢复：

\[
h=(q,\ \mathcal H_{\le t},\ \mathcal V_{\le t},
   \text{视图与坐标绑定},\ n_h,\ \text{剩余预算}).
\]

这里包括问题、完整历史文字、已经实际提供给模型的图像观测、视图编号及其坐标关系、已用裁图数和剩余 token/轮数预算。策略快照、预处理器、图像尺寸处理与采样参数固定。

工具后端的原图资源也要正确恢复，但**不向停止分支额外提供原先没看到的高分辨率像素**。GT 只用于最终评分，不进入任一分支的可见输入。

现协议的 WORD 已规定本轮是 `commit/abstain`，还是 `locate/re_examine/fallback`。因此不能固定一段已经说“继续找”的 WORD/caption，再把最后的 grounding 标签换成 answer，称为同状态停止反事实。[协议实现][protocol]

### 4.2 两个操作

| 分支 | 操作 |
|---|---|
| \(S\)：停止取新视觉信息 | 从共同 \(h\) 生成合法的回答回合，不执行新裁图 |
| \(C\)：继续 | 从共同 \(h\) 生成合法的裁图回合，真实执行该裁图，然后按同一固定策略和原剩余预算自然续跑到终局 |

两支各自生成与所选模式一致的 WORD、caption 和动作，不能共享已经承诺某个动作的本轮文字。

模式条件采样规则必须明确。如果实现只能强制 `commit` 和某个具体裁图模式，那么估计量就应命名为这两个**具体干预协议**的比较，不能冒称已经获得自然策略全部 stop/continue 模式的价值。

原始失败、无效终止、超限都应保留，不能反复重采直到凑到“合法且成功”的分支。

### 4.3 使用与当前目标一致的价值

令 \(M_a\) 为从 \(h\) 之后实际执行的裁图次数。继续分支的 \(M_C\) 包括被要求执行的第一裁，以及其后全部自然续跑裁图；停止分支 \(M_S=0\)。

估计：

\[
\widehat Q_\lambda(h,a)
=
\frac1K\sum_{k=1}^K
Y_{a,k}\left[1-\lambda(n_h+M_{a,k})\right].
\]

同时报告：

\[
\widehat p_a=\overline{Y_a},\qquad
\overline{M_a},\qquad
\overline{Y_aM_a}.
\]

最后一个联合项不能省，因为

\[
Q_\lambda(h,a)
=(1-\lambda n_h)p_a-\lambda\mathbb E[Y_aM_a],
\]

一般不能用 \(p_a\mathbb E[M_a]\) 替代 \(\mathbb E[Y_aM_a]\)。

**已发生的裁图数也不能随意删掉。** 在当前成功门控奖励中，过去成本乘着未来是否答对；成功概率随动作变化，它不是跨动作常数。

定义

\[
D(h)=Q_\lambda(h,S)-Q_\lambda(h,C),
\]

则

\[
D(h)
=
(1-\lambda n_h)(p_S-p_C)
+\lambda\mathbb E[Y_CM_C].
\]

这把两件事拆开了：立即回答是否损失正确率，以及继续观察需要付出多少成功路径成本。

**\(D>0\) 本身不等于精度无损。** 当前奖励允许精度与成本发生交换，因此必须同时看 \(p_S-p_C\)，不能只给一个效用分数。

### 4.4 为什么这比“裁前／裁后能否马上答对”更适合保护 recover

设某次裁图前后，模型立即回答都容易错，但接下来再找一次可以答对。只看 answer-now 的相邻差，可能把第一步探索记成没有收益；完整继续分支则能把延迟恢复的收益计入 \(Q_C\)。

反过来，两支各四次全错，只说明这次小样本没有观测到收益，**不能给停止正标签**。当前成功门控奖励下，这时两支样本奖励都为零。

每臂 \(K=4\) 的经验成功率分辨率是 25 个百分点。原 λ 实验的“两点操作门”不能搬来当作单个状态的四次分叉安全界限。近零差、双全失败、独立续写下频繁变号，都应记为**无法判别**。[Stage 0 的统计边界][stage0]

### 4.5 哪些 token 接受什么 loss

本轮推荐的是诊断，所以答案可以很明确：

| token / 数据 | 当前 λ 对照 | 上述无训练 probe |
|---|---|---|
| 实际生成的 WORD、caption、grounding/框、终答 token | 通过 response mask 接受原轨迹级 RLOO 信号 | **无 loss、无参数更新** |
| 输入问题、注入的工具回执、图像占位与 padding | 不作为 actor policy loss 的预测目标 | 无 loss |
| 为 probe 强制注入的模式或前缀 | 不是自然 actor 采样 token | 无 loss |

当前实现没有独立的停止 loss 或框定位 loss；终奖落在最后一个生成位置，再由 RLOO 处理并广播到实际生成的 assistant token。[RLOO 配方][rloo]、[mask 与奖励实现][contracts]

我不建议现在把强制平衡采出的两支，直接广播成一个新 advantage。C3/TWICE 的相关保证依赖替代动作的采样分布；强制比较相反模式，首先估计的是**两个干预协议的价值差**，不能直接借用原论文的无偏 actor advantage 结论。[arxiv.org](https://arxiv.org/html/2603.06859v4?utm_source=chatgpt.com)

同样，“只给动作 token 加辅助 loss”不等于其他能力被锁住。共享参数仍会影响其他状态。旧首动作实验已经提醒了这一点，也没有证据把失败归结为单一的“BCE 饱和”。[第二轮 Pro 核查][pro2]

### 4.6 最小规模、对照与失败条件

**先检查已有轨迹是否真的含相同完整 \(h\) 的分叉。** 同题四次自然采样、旧首轮 4+4 分叉，都不能自动替代后续状态的对照。

只有缺数据时，才考虑未来小规模续跑。例如：

- 先固定 **16 个开发状态、每支 4 条后缀，共 128 条分支续跑**，用于检查是否存在可辨识信号；
- 同时记录额外生成 token、图像编码、工具执行和 GPU/墙钟开销，回放校验也计入；
- 该数量只是一个小型诊断上限示例，**没有非劣或统计功效保证**。

最简单的对照就是同 \(h\) 的 \(S\) 与 \(C\)，并保留原自然轨迹作为行为参照。若根据一部分续写选择动作，要用独立续写评价；这仍是同状态的重复测量，不能冒充新题泛化。

以下任一情况成立，就不进入训练设计：

- 输入或多图状态不能可靠恢复；
- 优势只出现在强制协议中，无法对应自然可执行动作；
- 独立续写下差值不稳定，或多数位置都无法判别；
- 省步伴随必要恢复收益的明确损失；
- 只在精挑的案例上看到空间，缺少它在实际轨迹中的覆盖证据。

逐图审查只帮助选位置。公开注释中的 c04 可提示一个中间决策候选，但在没看图、没做分叉前不能认定其多裁冗余；c05/c06 所述的补表头、跨视图绑定等情况，则提醒不能把“再确认”一律判无用。c01 的末轮读数或答案映射纠错，即使有效，也不能直接解释此前的额外裁图。[公开审查记录][visualreadme]

## 五、PBRS 应当怎样放回正确的位置

### 5.1 先纠正历史归纳

**PBRS 不要求 \(\Phi=V^\pi\)。**

第一轮 Pro 的一般 telescoping 推导本来正确；docs/32 后来的归纳，把“PBRS 的保策略条件”和“局部 TD 项能否作为正确 advantage 的条件”合在了一起。[第一轮 Pro §4.3][pro1]

固定势函数下，

\[
F_t=\gamma\Phi(h_{t+1})-\Phi(h_t),
\]

于是

\[
\sum_{t=0}^{T-1}\gamma^tF_t
=
-\Phi(h_0)+\gamma^T\Phi(h_T).
\]

势函数可以是启发式函数。关键是差分形式、折扣一致性和终止边界，而非必须等于真实价值。原论文也将势函数与状态价值初始化区分开来。[jair.org](https://jair.org/index.php/jair/article/download/10338/24713/19085?utm_source=chatgpt.com)

### 5.2 终止和折扣不能省略

对当前有限轨迹，最直接的安全约定是所有真正终止状态的势为零：正常回答、无效终止、预算耗尽等都要一致处理。

如果某个“截断”只是训练切片，任务理论上还要继续，则需要一致的 bootstrap 或边界补偿，不能一边当未终止，一边丢掉后续抵消项。

\(\gamma<1\) 可以用于 PBRS，但必须与原目标的折扣一致。若原来优化不折扣终奖，现在为了奖励早停改成按轮折扣终奖，那么**产生早停偏好的，是改变后的折扣目标**。

非零终止势是否改变目标，取决于末项是否随路径变化。也不能笼统说“终止势只要不为零就必然改变目标”：例如 \(\gamma=1\) 且所有终止势为同一个常数时，它仍可只是公共常数。

### 5.3 轨迹级 RLOO 与按轮回报的区别

当前若 \(\gamma=1\)、终止势为零、同题 rollout 起点势相同，则

\[
R_i'=R_i-\Phi(h_0).
\]

因此

\[
\operatorname{LOO}(R')_i
=
\operatorname{LOO}(R)_i.
\]

**当前轨迹级 RLOO 的 advantage 完全不变。** `test_pbrs_rloo.py` 检查的是这一代数事实，不是一次证明训练效率改善的实验。[Stage A][stageA]

若改为每轮的 return-to-go，则在边界正确时：

\[
G'_t=G_t-\Phi(h_t).
\]

它可以作为状态基线改变有限样本的估计性质；若价值函数也做一致变换，理想 advantage 又可以保持一致。实际 PPO、函数逼近和优化过程可能因此变化，但不能从 telescoping 推出“中间步数会下降”。

而以下操作已经不是这一套严格 PBRS：

- 只给裁图轮写入局部势差；
- 用势差替换原 advantage；
- 给势差单独归一、裁剪，却仍引用原抵消证明；
- 漏掉终止抵消项。

fc 属于需要另行分析的局部系数替换，不能借 PBRS 自动获得保目标保证。[fc 代码][fccode]

还要注意，逐裁图即时给 \(-\lambda\)，终局给 \(Y\)，得到的是

\[
Y-\lambda N,
\]

不是当前的 \(Y(1-\lambda N)\)：它也向失败探索收费。即使事后将每裁成本写成 \(-\lambda Y\)，也要处理它对未来正确性的依赖，不能随手套用“过去奖励与当前动作无关”的普通 reward-to-go 推导。

**所以，PBRS 在这里值得保留为估计器与边界条件的审计工具；目前还没有证据支持把它指定为下一轮减少中间步数的方法。**

## 六、现有 λ 实验三类结果：每类只接一个最小动作

以下都保留 docs/33 的原判读。新增分析明确属于探索性解释，不改变原实验的过门与否。

### 情况 A：少裁，且精度通过现有操作门

**支持的结论：**该 λ 在当前配方和单个训练 seed 下，提供了可用的成本—表现权衡。

**只做一个最小后续动作：对已有 E1/E2 轨迹做配对归因汇总，0 新 GPU。**

同一份汇总回答：

- 减少了多少第二次及以后的裁图；
- 对→错和错→对分别发生在哪里；
- E2、各 benchmark、超限/无效结束是否出现集中回归。

如果节省主要来自第一次观察消失，而后续裁图几乎没变，仍按原规则记录过门，但不能把它宣传成“中间冗余已解决”。如果确实压低后续步数且没有明显集中伤害，就保留这个简单方案为新基线，**不自动追加 PBRS**。

之后才是独立确认问题：冻结选择，补训练 seed 和未参与选择的数据。那是后续确认阶段，不是现在再开一组方法搜索。

### 情况 B：少裁，但掉分超过原门

**支持的结论：**当前代价方案没有达到预定的准确率—效率要求。

**只做一个最小后续动作：审查“少裁且由对变错”的配对病例，先用已有日志，0 新 GPU。**

从共同历史中找第一个分歧位置，区分它更像：

- 已有证据还不够便提前结束；
- 选择了不同的裁图位置，导致后续信息变差；
- 轨迹仍取到了信息，但最终答案处理出错。

这只是定位疑问，不把两条自然轨迹的差异当因果证明。若日志不能判断，才把少量明确的中间位置送入上一节的同 \(h\) 无训练比较。

只有当这些位置反复显示“继续有恢复收益，而另一些位置可以安全停止”，才有理由考虑选择性的动作机制。**掉分本身不等于信用分配已经被诊断为根因。**

### 情况 C：仍然不少裁

**支持的结论：**在已测试剂量、训练预算和配方下，没有得到预期的少裁效果。

**只做一个最小后续动作：检查现有日志中成本项是否按预期进入了训练，0 新 GPU。**

核对实际 score、λ、mask、分组后的 \(A_{\text{cost}}\)、有正确样本且长度不同的组、全错组和触顶轨迹，以及日志里已有的梯度范数/裁剪信息。

这一步要区分：

- 系数或接线没有兑现；
- 信号确实改变了，但行为没有响应；
- 正确轨迹已主要集中在一次裁图，而长尾多为全错组，当前成功门控奖励缺少直接的长度区分信号。

可在固定旧账本上重算不同 λ 的优势，说明代数变化；**不能把这种离线重算当成新 λ 策略的性能预测**。

若信号兑现仍不减步，就按原规则带着这一具体失败返回导师讨论，不默认继续加大 λ，也不直接展开四臂训练。

### 三类结果共同的统计边界

- **原两点门是操作性决策门。** 科学非劣需要研究者先决定可接受损失 \(\delta\)，再冻结比较与检验设计；不能由本轮代替你选择。
- 若将来做非劣检验，应考察准确率差区间是否整体高于 \(-\delta\)；“区间包含零”不是非劣证据。
- 同题四采样、共享图片、多 checkpoint 的相关性要保留。按题/图片聚类的区间不能覆盖训练 seed 的不确定性。
- 当前反复使用的 E1 和挑选出的 probe 状态属于开发材料。按题目及共享图片来源隔离确认集，冻结 λ、checkpoint 选择规则和任何后续阈值后再确认。
- 同题换一批续写，只是减少同状态估计的噪声，不是独立题目上的泛化确认。

## 可直接转给导师的短总结

老师，这轮把主线收回到：在尽量保持答题和 recover 的前提下，减少第一次观察之后的额外步骤。直答少可以合理，不再作为必须修复的问题。

已确认原 GRPO 的组内标准化会改变裁图成本的作用尺度；RLOO 避开了这一点，但 λ=.01 没有稳定减少裁图。旧强成本组有明显效率信号，不过单种子、准确率区间包含零都不足以证明非劣。零 GPU 统计支持“成本可能偏弱”的假说，尚不能证明唯一瓶颈就是力度；四采样最短正确轨迹也只是经验参照，14% 不是已验证可无损删除的比例。

建议先按原规则读完已启动的 λ=.05/.10 对照。过门后先查节省是否来自后续裁图及是否有集中回归；少裁掉分则查由对变错病例的首个分歧；仍不少裁则核对成本信号是否实际进入训练。这三步优先使用已有日志。

只有出现具体的中间停/继续疑问且现有数据不足时，再考虑同一合法中间状态的无训练分叉，完整续跑以计入延迟 recover。这个思路已有接近前作，应如实定位为 VLM 应用改造。当前不叠加新信用模块或 PBRS；纯 telescoping 在轨迹级 RLOO 下不会新增效率驱动力。
