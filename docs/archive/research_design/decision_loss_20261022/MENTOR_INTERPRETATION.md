日期：2026-10-22。作者：Codex。状态：**已有材料的解释、匹配与下一步设计输入；不是新算法验收、创新性结论或实验启动记录。**

## 1. 这次的视角转换

导师最新建议是：在同一个状态下，比较“现在直接回答”和“先裁图再继续”的平均收益，把收益差直接用于监督首次动作选择。

这把宽泛的“信用分配”收窄到一个可训练对象：**动作标签的相对概率**。我们先回答“此刻选哪条路更划算”，不必先为每句 caption 建立独立的因果价值，也不必先解决整条轨迹的所有功劳和责任。

导师原文：

> 我觉得直接监督动作的选择吧
> 我写了一组实现，你可以参考一下
> t_{answer}、t_{crop}是两个动作标签，用完整标签的序列概率
> 实现的话就是在还没有输出<answer>或者<grouding>的时候保存相同的的prefix，用h表示（在这套公式里面），分为两个分支
> 一个是直接回答，另一个是crop后continue
> 比如每个分支生成4条，可以沿用现在的奖励算平均收益，再用收益差来监督首次的动作选择
> 这样可以强行控制一下base model的第一步

来源：Conversation.md 第 170 行起（内部来源：`lark/Conversation.md:170`，此包未发布）。摘录去掉了文件里的 NUL，保留原词。文件末尾缺独立说话人标记，本次依据用户明确归属，将这段作为导师建议；不补造日期或完整飞书元数据。原文 `<grouding>` 与现有协议的 `<grounding>` 拼写不同，执行应以核验后的真实协议为准。

当前问题可以写为：

> 固定库 A 的 SFT 起点与 RLOO 配方，增加同前缀的双分支收益监督，能否使模型在直答足够时少裁图，在裁图有收益时保留裁图，从而改善准确率与推理成本的权衡？

它属于动作层面的信用分配和策略改进候选。不能由这个名称推出“所有效率问题的根因已经证明是信用分配”。

## 2. 必须区分的四个层次

| 层次 | 回答什么 | 当前对应物 | 不应混同 |
|---|---|---|---|
| 任务收益 | 完成任务后，我们偏好什么结果？ | 答对，同时少裁图的 R | 不是 advantage，也不是梯度落点 |
| 优势计算 | 同批轨迹的收益如何变成相对更新信号？ | GRPO 的组均值/std；RLOO 的留一均值 | 信号稳定不代表已经学会高效选择 |
| 信用落点 | 哪个输出接受什么信号？ | 整条轨迹、某轮、某类 token、动作标签 | 更细粒度不自动更准确 |
| 策略监督 | 用什么损失改变选择？ | 用两条路线收益差加权的动作交叉熵 | 不是保持期望梯度不变的基线替换 |

导师先要求干净 RLOO 对照，是在拆开奖励与优势计算的影响。现在增加动作损失，是在明确“比较的单位”和“信号的接收位置”。两件事相关，但不是同一个实验。

现有报告中的 RLOO 对照支持“更换优势形式后未复现旧裁图代价塌缩，但没有减少裁图”这一设置下的观察。它不排除成本系数、探索、能力、有限采样或实现等其他解释；本轮没有重新验收训练原始日志。

## 3. 导师公式与直观解释

以下完整公式来自用户本轮之前的消息；Conversation 文件末尾只保存了实现文字。

\[
R(\tau)=\mathbf1[\mathrm{answer}(\tau)=y^\star]
\left(1-\lambda N_{\mathrm{crop}}(\tau)\right).
\]

\[
\widehat Q_a(h)=\frac1K\sum_{k=1}^{K}R(\tau_k^a),
\qquad a\in\{\mathrm{answer},\mathrm{crop}\}.
\]

\[
\Delta(h)=\operatorname{stopgrad}\left(
\widehat Q_{\mathrm{answer}}(h)-\widehat Q_{\mathrm{crop}}(h)\right),
\qquad d(h)=\mathbf1[\Delta(h)>0].
\]

\[
p_\theta(h)=\frac{\pi_\theta(t_{\mathrm{answer}}\mid h)}
{\pi_\theta(t_{\mathrm{answer}}\mid h)+\pi_\theta(t_{\mathrm{crop}}\mid h)}.
\]

\[
\mathcal L_{\mathrm{decision}}=-\mathbb E_h\left[
|\Delta(h)|\left(d(h)\log p_\theta(h)
+(1-d(h))\log(1-p_\theta(h))\right)\right].
\]

\[
\mathcal L_{\mathrm{total}}=\mathcal L_{\mathrm{RLOO}}
+\beta\mathcal L_{\mathrm{decision}}.
\]

先在模型即将输出动作标签的位置保存状态 h，包括问题、学生实际看到的图、历史、当前已生成的 caption 和准确 token 前缀。复制同一状态，分别进入 answer / crop 分支，每边多次继续到终答。

- R：答错为零；答对时按裁图次数扣成本。失败轨迹没有这项成本扣分。
- Q：当前策略选定该动作之后，整条后续路线的平均收益；不是另训一个 critic，也不是纯视觉信息增益。
- Δ 的符号：监督哪个动作；绝对值：这条监督的强度。stopgrad 让收益估计作为固定目标。
- p：两个标签之间的相对偏好，不是答案正确率，也未覆盖所有可能的无效输出。
- λ：收益中效率的价格；β：辅助损失相对 RLOO 的强度。二者不能混为一个参数。

假设 λ=0.01，crop 分支每条恰好裁一次，K=4：

| answer / crop 的采样结果 | Q_answer | Q_crop | 辅助监督 |
|---|---:|---:|---|
| 两边都 4/4 对 | 1 | 0.99 | 轻微偏向回答 |
| 3/4 对 / 4/4 对 | 0.75 | 0.99 | 偏向裁图 |
| 4/4 对 / 2/4 对 | 1 | 0.495 | 偏向回答 |
| 两边都 0/4 对 | 0 | 0 | 无辅助信号 |

该表是公式示例，不是实验测量。训练时用真值评分，真值不应进入策略可见的 h。推理时不需要真值和额外分支，模型直接输出动作。

## 4. 具体监督哪些输出

对完整标签的 token 序列计算：

\[
s_a(h)=\log\pi_\theta(t_a\mid h)
=\sum_j\log\pi_\theta(t_{a,j}\mid h,t_{a,<j}),
\quad p_\theta=\sigma(s_{\mathrm{answer}}-s_{\mathrm{crop}}).
\]

令 z=s_answer−s_crop，则单状态辅助梯度为：

\[
\frac{\partial\ell_{\mathrm{decision}}}{\partial z}
=|\Delta|(p_\theta-d).
\]

新增损失直接计分的位置是两种完整动作标签，而不是当前整轮 caption、裁图坐标或答案正文；原有 RLOO 仍负责原本参与训练的输出。共享模型参数意味着其他行为仍可能受间接影响，“标签 loss mask”不等于模型其他部分绝不会变化。

必须核验两条序列来自同一 token 前缀与图像绑定，不能分别重写 caption，不能只取一个共享的 `<` token，也不能擅自把序列 log 概率改成长度平均。标签分词、前导空白、边界均属于待 Pro 明确并由 Codex 验证的实现契约。

辅助损失改变训练梯度；可以仍以同一个任务收益为依据，但不能再称为“只改基线、期望梯度不变”。

## 5. 为什么之前的方案没有自然走到这里

旧方案不是完全没用卡。refined_candidate.json（内部来源：`.forge/runs/tool-credit-assignment/refined_candidate.json`，此包未发布） 的 gap_closure 已引用 K19。旧 idea_card.md（内部来源：`.forge/runs/tool-credit-assignment/idea_card.md`，此包未发布） 明确选择后续决策点的 answer-now 值，作为动作无关基线，并把“保持 RLOO 期望梯度”作为设计约束。

因此至少存在两种问题：

1. **检索匹配不够细**：把所有东西都放进“credit assignment / GRPO”大类，没有系统区分收益估计、信号变换、梯度接收对象。
2. **命中卡之后的使用选择偏离目标**：已经找到 MC 价值估计，却优先使用为不改目标的基线；而导师现在需要的是直接教动作取舍。

不能将全部历史偏差归为“我们没有找到现有卡”，也不能说一张更好的卡必然会解决它。用户和导师的具体问题高于卡片预设；不应为了强调理论不变性而替换研究目标。

### 6.3 之前的 GRPO/advantage 问题覆盖与缺口

旧 repair_degenerate_signal 卡已经提到过滤无信息组、leave-one-out、优势重缩放及简单基线对照。K16 有成功率筛选，K17 有 token 权重，K18 有辅助 loss，K22 有过程 reward。

但本次没有找到一张卡完整规定“本项目的 GRPO→RLOO 对照 + 同 h 双动作 K 次采样 + |Δ| 加权标签 BCE”。也不能因为某张卡提到 GRPO，就把其奖励、normalizer、clipping、loss reduction 当成我们的实现。

缺口不是继续造一堆 card，而是补一张**比较表**：相同信息分别用作 baseline、reward、token weight、action CE 时，期望梯度和行为方向怎样不同。具体推导交给 Pro。

不是“遇到问题就加 loss”。顺序是：**需要改变的行为 → 可比较的替代动作 → 判别优劣的证据 → 接受监督的输出 → 损失 → 能推翻方法的对照。**

导师口述提到的论文/算法名称不自动成为技术事实。例如“全答对没有优势信号”要区分奖励是否还包含变化的成本；DAPO、Dr. GRPO 的精确形式须回原文和代码核验，不能由一段口述补全。

## 8. 下一步实验应聚焦什么（建议，未启动）

主线候选：**RLOO + 首次动作收益差监督**。不同时重构 SFT、不同时加 PRM、不同时改 DS/KL/clip，以免无法判断变化来自哪里。

先由 Pro 明确算法，再由 Codex 做本地实现核对。最小 CPU 检查包括：Δ 正负与更新方向、Δ=0、完整标签多 token 的概率、同 prefix、loss mask、λ/β 和 reduction 不被隐式重归一化。它们证明实现与公式一致，不证明研究有效。

研究对照至少区分两个问题：

- 固定更新次数的 RLOO vs RLOO+decision：加入这条监督后的整体效果与新增成本。
- 若要把收益归因于监督形式，而非额外 rollout：需要对同等额外预算/信息怎样给到简单基线作设计。具体预算匹配由 Pro 提出，不默认一次跑完整矩阵。

主要结果仍是准确率与裁图/token 成本的联合表现；报告错框后的结果以及总是 answer/crop 的塌缩风险。准确率“不显著下降”不等于已经证明不下降，应在确认实验前定可接受界限和区间。标签拟合率、动作 CE 降低、符合 Δ 的比例只是中间诊断。

训练额外分支的 token/GPU 时间必须单列。固定同批数据、模型和更新次数与固定总算力不是同一公平口径。

当前不再以“至少八个 caption 正确但答错病例”作为动作选择研究的前提：那是证据利用路线的门槛。原有有效结论仍保留，不能为了推进改写门槛或原结果。

## 9. 已知边界与交给 Pro 的关键问题

1. K=4 的 |Δ| 是估计差，不是置信度；采样噪声可能翻转监督方向。
2. 两边都失败时辅助项为零，只代表无额外动作监督；RLOO 仍可能处罚整条失败轨迹，不等于已经保护所有必要探索。
3. Q_crop 是整个“裁图后继续”的价值，不是纯视觉因果贡献；变差可能来自后续推理。
4. 首次动作监督不能保证后续停止和 recover 已解决；不自动扩成每轮监督。
5. 同 h 要包含实际 caption。若 caption 已经承诺一种动作，如何定义有效分叉，需要 Pro 与协议核验。
6. 训练时依赖真值评分可以接受，真值不得进入 h；不声称在无答案测试时在线计算 Δ。
7. 加权 BCE 不是原策略梯度的无偏重写；不应以“不改变期望梯度”作为硬约束。
8. 不将 |Δ| 按 batch 总权重随意归一化：这可能抵消 λ 所表示的小成本尺度；是否使用固定尺度归一化应显式决定。
9. 本次是既有卡库匹配，未做新的两通道查新。VisionThink、AdaTooler-V 等是 K11 的历史来源线索；CounterCredit/TACO 等旧近邻也应保留核对入口。没有重新核全文前不能新增论文论断或宣布创新。

## 10. 后续固定的使用方式
