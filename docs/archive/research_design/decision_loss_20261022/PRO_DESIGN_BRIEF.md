## 固定问题与背景

学生是 Qwen3-VL-4B 的库 A SFT 起点，工具为 crop，现有协议是 caption 后跟 `<answer>` 或 `<grounding>`。目标是尽量保住最终正确率与 recover 能力，减少无效裁图和推理长度。现有 RLOO 对照没有复现旧成本 GRPO 塌缩，但未减少裁图；这不是信用分配根因的证明。

导师的新干预：在首次动作标签前保存同一真实 h；answer 与 crop-then-continue 各采样 K 次（建议起点 4）；用终答正确性乘 (1−λN_crop) 算均值；以 stopgrad(Q_answer−Q_crop) 的符号为标签、绝对值为权重，训练两个完整动作标签的相对概率；加到原 RLOO 上。

## 补充事实（CC，2026-10-22 追加；不改上文）

1. **四格 RL 正在跑，不是废案。** fc（裁图轮 token 得 c = v(s_{t+1}) − v(s_t) − λ，v = 策略此刻直接作答的 fork 正确率）与 zero 对照（裁图轮只得 −λ）各占 2 卡，同 seed 42、同数据顺序，与已有 RLOO λ=0.01（r1）配对；北京时间 10-23 约 07:30 出 E1/E2 结果。预注册判据见 `.forge/studies/rl-objective-credit/` 的 t-fourcase-rl 与 `prep_fcz/PREREG.md`。新设计请以 r1 为共同对照，沿用同 seed/数据顺序，避免重跑基线。
2. **fc 是势能差形式。** c 等于以 Φ = answer-now 值为势能的差分，但它*替换*裁图轮优势，而 Ng 等 (1999) 的塑形是*加到*奖励上（γΦ(s')−Φ(s)），后者保最优策略。导师说后续用势能方程做信用分配；请推导两者区别，fc 结果可作该步的经验输入。
3. **已有 fork 设施及口径差异。** `actions/022-plan_test/easyr1_caption.py` 已能在同一 token 前缀上分叉（首轮按题共享 M0=16，后续 M=4，预填 `<think>\nStep t | commit\n`），近似 Q_answer。差异：(a) 首轮现在在 caption *之前*分叉，导师的 h 在 caption 之后、动作标签之前；(b) 尚无"强制 `<grounding>` 后自主续到终答"的 Q_crop 分支，它是多轮 rollout，成本远高于直答 fork，需单列预算。当前 fc 每步约 290–430 s（与 zero 共机），r1 约 178 s。
