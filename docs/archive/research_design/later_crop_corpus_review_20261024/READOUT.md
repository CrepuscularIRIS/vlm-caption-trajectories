## 给导师的一页说明

**问题已经明确：模型可以先看图，但拿到足够信息以后，不应该把能两步完成的题拖成四五步；信息不足或看错位置时，仍应允许继续找。** 首轮直答率低本身不是本阶段必须修复的问题。

导师连续提出 advantage、四种情况的信用、动作选择监督、势函数，可以理解为逐层排查：

| 层次 | 用人话说 | 当前证据回答到哪里 |
|---|---|---|
| 优势估计 | reward 写了“小额裁图费”，经过标准化后，还真的是小额吗？ | RLOO 避开了原组内 std 带来的特定尺度问题；不意味着效率已解决。 |
| 目标力度 | 模型是否在乎节省一两步？ | λ=.01 没有稳定少裁；更大 λ 的干净对照正在按已有记录推进，结果未在本轮核验。 |
| 信用分配 | 最后答对，是否应该连中间多余裁图也一起奖励？ | 已测几个接法未达目标，不能外推为所有信用方法都无效。 |
| 中间动作判断 | 已经看过这些图，现在答还是再找一次更好？ | 首轮 Stage 0 不能回答后续状态；自然短轨迹也不能替代同状态分叉。 |

**现阶段推荐先按原规则看完 λ=.05/.10，而不是立即叠加新的 loss。** 这不否定信用研究；它避免在还没知道代价强度能解决多少之前，继续换模块。

建议额外报告一个很直接的量：

$$\mathbb E[N]=P(N\ge1)+\mathbb E[(N-1)_+].$$

右边后一项就是每道题平均用了几次“第二裁及以后”，用全题分母。它能检验是否真的压缩了中间步骤，但它本身仍不等于无效步骤数。E2 还应报告实际接受首次裁图扰动的比例，防止更多直答导致扰动覆盖变小，被误读为恢复能力更强。

## 算法核对：当前奖励不能悄悄换掉

保持导师的 $R=Y(1-\lambda N)$。在中间状态 $h$，已用裁图 $n_h$，分支之后还用 $M_a$ 次：

$$\widehat Q_\lambda(h,a)=\frac1K\sum_k Y_{a,k}[1-\lambda(n_h+M_{a,k})].$$

令停止分支 $S$ 不再裁图，继续分支 $C$ 允许原预算内自然续跑，则

$$D(h)=(1-\lambda n_h)(p_S-p_C)+\lambda\mathbb E[Y_CM_C].$$

这个展开与原奖励一致。需要同时保留三个边界：

- 已经花的裁图成本乘着未来是否正确，分支正确率不同时不能直接丢掉；也不能把 $\mathbb E[YM]$ 换成 $\mathbb E[Y]\mathbb E[M]$。
- $D>0$ 表示当前效用偏好停止，不表示精度无损；必须另报两支正确率差。
- 强制两种模式测得的是指定干预协议的差值，不自动构成无偏 actor advantage。当前推荐 probe 无 loss、无参数更新。每支四条只是粗测，不能认定单状态精度差小于两点。

Pro 提出的“16 状态×两分支×4 后缀”只是未来规模示例，不是已批准预算、功效保证或已启动任务。

## 对现有表述的核对与保留事项

- **0.45** 是所有正确样本相对本题最短正确样本的平均额外裁图，包含参照样本自身的零值；**14%** 是经验额外次数占全部裁图的比例，不能称已验证可无损删除比例。
- E2 的 **0.78** 同样相对于 E2 自身最短正确样本，不是 E2−E1 的总裁图差。
- **2–5%** 是优势幅度加 token 权重的代理，不是实际参数梯度份额；它支持做剂量检验，不能证明唯一根因。
- 准确率差“不显著”不是非劣证据。原操作门保持，后续科学确认需要独立冻结界限、数据与选择规则。
- PBRS 的势函数不必等于真实 $V^\pi$。在当前 $\gamma=1$、终止势为零、同题共同起点的轨迹级 RLOO 中，严格势差只增加共同常数，LOO 后抵消。逐轮估计或其他信号路由另需分析，不能由此保证少步。
- 原文摘要使用 r1 精度约 **.664**，而 docs/33 表和 docs/30 基础表为 **.663**，docs/30 后文又出现 .664。此次保留 Pro 原文，不擅自合并口径；正式汇报以指定 run/eval 的原始计数及固定四舍五入规则为准。
